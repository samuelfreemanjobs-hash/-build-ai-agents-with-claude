## Target audiences

### 1. 3PL / freight brokers (primary)

- **Pain:** Buried in RFPs, can't respond to all
- **Win:** Respond to 3× more RFPs = 3× pipeline
- **Detroit fit:** Auto supplier lanes, dedicated milk runs

### 2. Trucking companies

- **Pain:** Generic proposals lose to specialists
- **Win:** Customized, traced responses

### 3. Warehousing / distribution

- **Pain:** Long technical RFPs take days
- **Win:** Compliance-checked proposals fast

### 4. Freight forwarders

- **Pain:** International complexity + compliance
- **Win:** Auto-insert certifications with gap flags

1. Logistics-specific (not generic proposal software)
2. KB learns from **your** wins
3. Compliance library = risk mitigation
4. Pricing traceability — schema-enforced, not prompt-hoped
5. Operator console makes guarantees visible
