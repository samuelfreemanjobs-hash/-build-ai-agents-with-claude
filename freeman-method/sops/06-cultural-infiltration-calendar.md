# Cultural Infiltration Calendar™ (CIC)

**Plan campaigns that ride on cultural and identity-based momentum.**

---

## Calendar Overview

**Frequency:** Monthly planning, weekly execution

---

## Monthly Planning (First Monday of Month)

### Step 1: Map Context
- [ ] Complete [Context Clustering Grid™](../pillars/07-cultural-gravity-map/context-clustering-grid.md)
- [ ] Identify top 3 identity groups, trends, and movements
- [ ] Score clusters by relevance × reach ÷ effort

### Step 2: Build Calendar
- [ ] Populate [Cultural Touchpoint Calendar™](../pillars/07-cultural-gravity-map/cultural-touchpoint-calendar.csv) for the month
- [ ] Include: holidays, industry events, cultural moments, news cycles
- [ ] Assign brand angle to each touchpoint (relevance ≥ 7)

### Step 3: Plan Integration
- [ ] For each touchpoint, define:
  - Content/action planned
  - Channel
  - Terms to seed
  - Cluster to activate

|---------------------|------|-------------|----------------|--------|
| | | | ☐ Yes ☐ No | ☐ Planned |
| | | | ☐ Yes ☐ No | ☐ Planned |

### Tuesday-Thursday: Execute
- [ ] Deploy planned touchpoint content/actions
- [ ] Run [Cultural Injection Checklist™](../pillars/04-contagion-engine/cultural-injection-checklist.md) for spontaneous opportunities
- [ ] Engage with identity group communities

### Friday: Measure
- [ ] Log reach and engagement for each touchpoint
- [ ] Update CTP (Cultural Touchpoint Penetration) score
- [ ] Plan next week's touchpoints
