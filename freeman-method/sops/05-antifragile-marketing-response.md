# Antifragile Marketing Response SOP™ (AMR)

**Turn negative press or market chaos into amplified brand power.**

---

## When to Activate

Trigger this SOP when:
- Negative press or viral criticism emerges
- Competitor launches a direct attack
- Market disruption threatens your category
- Social media backlash gains velocity
- Product failure or PR crisis occurs

**Speed is everything. Activate within 1 hour of detection.**

---

## Response Protocol

### Hour 0-1: Situation Scan

| Question | Answer |
|----------|--------|
| What happened? | |
| What's the emotion driving the backlash? (anger / fear / mockery / betrayal) | |
| Is there a valid point in the criticism? | |
| Is this organic or competitor-driven? | |
| Current reach/velocity? (low / medium / high / viral) | |
| Which pre-planned scenario from [Viral Backlash Plan™](../pillars/05-loop-leverage-protocol/viral-backlash-plan.md) matches? | |

**Decision:** ☐ Respond publicly ☐ Respond privately ☐ Monitor only

---

### Hour 1-4: Deploy Response

- [ ] Select response template from [Viral Backlash Plan™](../pillars/05-loop-leverage-protocol/viral-backlash-plan.md)
- [ ] Adapt template to specific situation
- [ ] Acknowledge valid criticism (never dismiss)
- [ ] Reframe toward your category narrative
- [ ] Embed proprietary terms in response
- [ ] Publish response (do NOT delete original content)

**Response checklist:**
- [ ] Tone: curiosity/confidence, NOT defensiveness
- [ ] Contains category language
- [ ] Acknowledges valid points
- [ ] Offers a reframe, not a rebuttal
- [ ] Includes a call to action that feeds a growth loop

---

### Hour 4-24: Amplify

- [ ] Turn response into standalone content (blog/thread/video)
- [ ] Feed all attention into growth loops ([Loop Leverage Protocol™](../pillars/05-loop-leverage-protocol/loop-leverage-protocol.md))
- [ ] Deploy narrative reinforcement via [Market Lexicon Playbook™](../pillars/06-market-lexicon-playbook/market-lexicon-playbook.md)
- [ ] Log in backlash tracker (below)
- [ ] Monitor sentiment shift

---

### Day 2-7: Compound

- [ ] Publish "what we learned" content
- [ ] Update product/positioning if criticism was valid
- [ ] Calculate net reach gained from backlash
- [ ] Update [Viral Backlash Plan™](../pillars/05-loop-leverage-protocol/viral-backlash-plan.md) with new scenario
- [ ] Brief team on lessons learned

## Rules (Non-Negotiable)

1. **Never delete** — Deleting amplifies the story
2. **Respond within hours** — Silence is interpreted as guilt
3. **Acknowledge before reframing** — Validate, then pivot
4. **Own your frame** — Every response uses your category language
5. **Feed the loops** — Every backlash response drives a growth loop
6. **Don't engage trolls** — Respond to the audience, not the attacker
