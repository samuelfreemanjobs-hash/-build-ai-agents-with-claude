# Momentum Multiplier Sheet™

**Template to connect every win into the next growth action**

---

## The Multiplier Principle

Every win (sale, review, post, mention) should automatically trigger the next growth action. No momentum is wasted between campaigns.

---

## Win → Action Mapping

| Win type | Immediate action | Next action | Loop it feeds |
|----------|------------------|-------------|---------------|
| New sale | Send thank you + ask for referral | Add to case study pipeline | Referral loop |
| Positive review | Screenshot + share on social | Ask reviewer to post on their platform | Social proof loop |
| Media mention | Amplify on all channels | Pitch follow-up story | PR loop |
| Viral post | Create follow-up content | Engage every comment | Content loop |
| Customer success | Request testimonial | Invite to community | Community loop |
| Speaking invite | Promote to audience | Repurpose into content | Authority loop |

## Momentum Loss Prevention

| Gap between campaigns | Risk | Prevention |
|-----------------------|------|------------|
| No wins logged this week | Momentum stall | Activate a loop manually |
| Wins logged but no multiplier action | Wasted opportunity | Same-day action rule |
| Actions taken but no follow-up | Leaky loop | Schedule next action immediately |
