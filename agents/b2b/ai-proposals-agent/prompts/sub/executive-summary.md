# Executive Summary Generator (SP-02a)

## Task

Write a compelling executive summary for this proposal.

## Inputs

- Client name: `{client_name}`
- Client pain points: `{pain_points}`
- Our key differentiators: `{differentiators}`
- Proposal value: `{total_value}` — **from pricing engine only, with trace citation**
- Key win themes: `{win_themes}`

## Requirements

- Length: 1 page maximum (300–400 words)
- Tone: Confident, client-focused, results-oriented
- Structure: Problem → Solution → Value → Call to Action

## Formula

1. **Opening:** Acknowledge their specific challenge
2. **Solution overview:** How we uniquely solve it
3. **Proof points:** 2–3 relevant metrics / case studies (KB-sourced, traced)
4. **Value proposition:** ROI or strategic benefit
5. **Closing:** Confidence statement + next steps

## Writing style

- Start with their business, not ours
- Use "you" and "your" more than "we" and "our"
- Lead with outcomes, not features
- Include 1–2 specific numbers that pop — **each with `[[trace:...]]`**
- End with momentum toward partnership

## Output

Polished executive summary ready for insertion. No pricing arithmetic in prose.
