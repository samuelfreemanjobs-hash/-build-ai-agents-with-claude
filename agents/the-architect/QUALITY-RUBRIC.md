# Quality Rubric — Self-Score Before Delivery

Score each dimension 1–10. Show the breakdown to the user. **Minimum ship threshold: 8.0 average, no dimension below 6.**

---

## Dimensions

### 1. Hook Power (T1 test)
Does the opening work at 3–12 words? Open loop? Implied story?

| Score | Criteria |
|---|---|
| 1–3 | Generic, ignorable |
| 4–6 | Clear but not compelling |
| 7–8 | Strong curiosity or identity pull |
| 9–10 | Would stop scroll / sell magazine / forward to a friend |

### 2. Specificity (Hopkins)
Numbers, scenes, names, timeframes, tested figures — or vague fog?

| Score | Criteria |
|---|---|
| 1–3 | Platitudes: "best," "lowest," "world-class" — water off a duck |
| 4–6 | Some specifics mixed with generics |
| 7–8 | Concrete facts, reason-why throughout |
| 9–10 | Hopkins-grade: preemptive truth, exact figures, every claim verifiable |

### 3. Mechanism & Belief
Why does this work? Is belief earned?

| Score | Criteria |
|---|---|
| 1–3 | Claims without support |
| 4–6 | Some proof, gaps remain |
| 7–8 | Clear mechanism + solid proof |
| 9–10 | Undeniable logic chain or demonstration |

### 4. Rhythm & Readability
Read-aloud test. Sentence variety. Slippery slide.

| Score | Criteria |
|---|---|
| 1–3 | Monotonous, clunky, AI-sludge |
| 4–6 | Readable but flat |
| 7–8 | Good flow, varied rhythm |
| 9–10 | Unputdownable; each line pulls to next |

### 5. Offer & CTA Clarity
One clear action? Friction removed?

| Score | Criteria |
|---|---|
| 1–3 | No CTA or confusing ask |
| 4–6 | CTA present but weak |
| 7–8 | Clear action + some friction removal |
| 9–10 | Inevitable next step; objections pre-handled |

### 6. Remarkability (Purple Cow)
Would someone share, quote, or argue about this?

| Score | Criteria |
|---|---|
| 1–3 | Forgettable category copy |
| 4–6 | Competent but not distinctive |
| 7–8 | Clear angle worth noting |
| 9–10 | Screenshot-worthy; changes how they think |

### 8. Outcome & Identity (Kern)
Selling transformation and Core Identity — or listing mechanics?

| Score | Criteria |
|---|---|
| N/A | Not a sales/promo piece |
| 1–3 | Feature dump, module counts, no future pace |
| 4–6 | Some benefits, weak identity |
| 7–8 | Clear outcome + future-paced scene |
| 9–10 | Core Identity aligned; reader sees who they become |

### 7. Teaching Installation (if educational)
Model, distinction, 10-min action — or info dump?

| Score | Criteria |
|---|---|
| N/A | Not a teaching piece |
| 1–3 | Information only |
| 4–6 | Some structure |
| 7–8 | Model + action step |
| 9–10 | Full Pagan/Woodsmall install; reader can teach it back |

---

## Output Format

```
## Quality Score: X.X / 10

| Dimension | Score | Note |
|---|---|---|
| Hook Power | /10 | |
| Specificity | /10 | |
| Mechanism & Belief | /10 | |
| Rhythm & Readability | /10 | |
| Offer & CTA | /10 | |
| Remarkability | /10 | |
| Teaching Install | /10 or N/A | |
| Outcome & Identity | /10 or N/A | |

**Weakest dimension:** [name] — [one-line fix if below 8]
```

If average < 8 or any dimension < 6: revise before shipping.
