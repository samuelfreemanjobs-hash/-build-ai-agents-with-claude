## The Value Equation

Perceived value is not price. It's the buyer's mental calculation:

```
VALUE = (Dream Outcome × Perceived Likelihood of Achievement)
        ÷ (Time Delay × Effort & Sacrifice)
```

### The four levers

| Lever | Job | Increase value by… | Copy moves |
|---|---|---|---|
| **Dream Outcome** | What they get at the finish line | Bigger, clearer, more desirable end state | Identity transformation (Kern Core Identity); specific numbers; before/after |
| **Perceived Likelihood** | Belief it will work *for them* | Proof, mechanism, guarantees, specificity | Case studies, "people like you," reason-why (Hopkins), mechanism name |
| **Time Delay** | How long until first win | Faster results, quick wins, speed guarantees | "First [result] in [timeframe]"; rung 1 of transformation ladder |
| **Effort & Sacrifice** | Work, pain, confusion, cost of change | Done-for-you, templates, shortcuts, removal of steps | "Without [pain]"; install-in-10-minutes (Pagan); DFY bonuses |

### Value Equation diagnostic (run before any offer build)

Score each lever **1–10** for the current offer draft:

| Lever | Score (1–10) | Weakest link? | Fix |
|---|---|---|---|
| Dream Outcome | | ☐ | |
| Perceived Likelihood | | ☐ | |
| Time Delay (inverse — higher = faster) | | ☐ | |
| Effort & Sacrifice (inverse — higher = easier) | | ☐ | |

**Rule:** Fix the **denominator** (time + effort) before inflating the numerator. A bigger promise with longer delay and more work = skepticism at sophistication 3+.

## Grand Slam Offer (Architect Definition)

A Grand Slam Offer is not a discount. It is:

1. **Differentiated** — cannot be compared on price alone (commodity escape)
2. **Premium-priced** — price signals category; stack justifies margin
3. **Stacked** — core + bonuses that each kill one objection
4. **Named** — ownable offer name + mechanism
5. **De-risked** — guarantee transfers risk to seller
6. **Scarce** — real limits on access, time, or bonuses (Cialdini ethics)

> Kennedy: *"Great copy can't save a weak offer."*  
> Hormozi: *"Engineer the offer first — then copy is assembly."*

## The 6-Step Grand Slam Build

Run in order. Save to `research/GRAND-SLAM-OFFER-TEMPLATE.md`.

### Step 1 — Starving Crowd + Dream Outcome (Halbert + Hormozi)

| Field | Spec |
|---|---|
| Avatar | One sentence — who, ability to pay, urgency |
| Dream Outcome | Functional → emotional → identity (Schwartz physical→functional) |
| Hell state | Specific before scene (numbers, time, emotion) |
| Heaven state | Who they become — not only what they get |

### Step 2 — Problem → Solution List (Objection Mining)

List every **obstacle** between avatar and dream outcome:

| Obstacle type | Examples |
|---|---|
| External | Time, money, tools, access, competition |
| Internal | Fear, imposter syndrome, past failure |
| Skill | Don't know how, overwhelmed, wrong order |
| Support | No accountability, no community, no expert access |

**Each obstacle becomes:** a module, a bonus, a guarantee clause, or a proof asset.

### Step 3 — Delivery Vehicle (What they actually get)

| Vehicle | Best for | Hormozi note |
|---|---|---|
| **1:1** | High-ticket, complex transformation | Highest likelihood, lowest scale |
| **Small group** | Coaching, cohort programs | Balance of access + scale |
| **Course / self-serve** | Scalable info products | Crush effort with templates + checkpoints |
| **Done-for-you** | Premium, speed | Crushes time delay + effort |
| **Hybrid** | Most info products | Core course + group calls + templates |

**Info-Product link:** Delivery vehicle maps to `INFO-PRODUCT-ARCHITECTURE.md` Phase 3–4.

### Step 4 — Trim & Stack (The Hormozi Core Move)

**Trim:** Remove anything that doesn't move the value equation. No filler modules. No "nice to have" bonuses.

**Stack:** Add deliverables until:

```
Perceived Stack Value ≥ 10× Price
```

| Stack layer | Job | Naming |
|---|---|---|
| **Core** | Primary transformation vehicle | Main program / service name |
| **Bonus 1–N** | Each kills **one** named objection | "[Outcome] [Format] — eliminates [obstacle]" |
| **Fast-action** | Rewards decision speed | Deadline-only bonus (real scarcity) |
| **Risk reversal** | Guarantee / trial / performance terms | Named guarantee |

### Bonus architecture rules

| Rule | Why |
|---|---|
| **One bonus = one objection** | Random bonus piles feel fake |
| **Name the bonus like a product** | Standalone value; could sell separately |
| **Assign dollar value** | Anchor stack total (honest estimates only) |
| **Bonus order = objection order** | Mirror sales page flow |
| **Fast-action bonus is real** | False deadline = trust destroyer |

**Kennedy alignment:** Bonuses = Kennedy element #1 (high perceived value) + objection killers.

### Step 5 — Guarantee Engineering

| Guarantee type | When to use | Risk level |
|---|---|---|
| **Unconditional** | Proven offer, strong fulfillment | Seller bears full risk |
| **Conditional** | Complex outcomes — terms must be clear | Shared risk |
| **Performance-based** | Measurable result promises | Highest proof, highest risk |
| **Anti-guarantee** | Premium exclusivity — "all sales final" | Only with extreme demand + proof |

**Name every guarantee.** Examples: *"30-Day Win-or-Work-With-Me Guarantee"* · *"Implementation Credit Guarantee"*

**Abraham link:** Total risk reversal = preeminent advisor posture.

### Step 6 — Name + Price + Scarcity

| Element | Standard |
|---|---|
| **Offer name** | Grand Slam name — not "6-week course" |
| **Mechanism name** | Supports Schwartz stage 3+ differentiation |
| **Price anchor** | Stack total → "you pay" → ratio check |
| **Payment terms** | Full pay vs plan — plan increases perceived access |
| **Scarcity** | Cohort cap, bonus expiry, price increase — **must be true** |

**Pricing doctrine:** Price is a **signal**. Commodity pricing attracts commodity buyers. Stack justifies premium.

## Copy Integration (After Offer Is Built)

Hormozi builds the offer **before** Carlton SWS copy. Copy sequence:

1. **Dream outcome headline** — numerator of value equation
2. **Proof block** — perceived likelihood
3. **Speed + ease block** — denominator killers
4. **Core reveal** — delivery vehicle
5. **Stack walkthrough** — bonus per objection (not feature dump)
6. **Guarantee** — named, specific terms
7. **Price anchor + CTA** — Galactic Phase 8 three-step offer
8. **Scarcity close** — true limits only

**Galactic Phase 8 (3-step offer):**

1. Here's what I've got → **Grand Slam name + core**
2. Here's what it will do for you → **Value equation in their words**
3. Here's what I want you to do next → **CTA + guarantee + scarcity**
