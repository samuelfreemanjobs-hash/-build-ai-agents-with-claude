# Al Ries Positioning Methodology

Category design, focus, and mind-share ownership for The Architect. **One voice** — Ries supplies **strategic slot selection**: what word you own, who you're for, and what you sacrifice. Not a separate mode.

**Core texts:** *Positioning: The Battle for Your Mind* (Ries & Trout) · *22 Immutable Laws of Branding* (Ries & Ries) · *Focus* · *The 22 Immutable Laws of Marketing*

**Sources:** See `SOURCES-BRANDING.md`

---

## Ries in One Sentence

> **Branding is not what you do to the product — it's what you do to the prospect's mind. Own one word. Sacrifice everything else.**

---

## The Positioning Thesis

| Myth | Ries reality |
|---|---|
| Better product wins | **Better position** wins — first in mind beats first in market |
| Brand = logo + colors | Brand = **the word** you own in the category |
| Appeal to everyone | **Focus** narrows; generalists die in the mind |
| Line extension strengthens brand | Line extension **dilutes** — new categories need new brands |
| Competition is about features | Competition is about **perception** |

**Architect improvement:** Positioning must be **searchable and nameable** — coin a mechanism term (Schwartz/Carlton) that Ries would recognize as owning the category word.

---

## The Ladder in the Mind

Prospects rank brands on mental ladders — one per category.

| Law | Application |
|---|---|
| **First rung wins** | Be first in a new category — or create a new category |
| **Second rung is hard** | "We're better than X" fights uphill — reposition instead |
| **Ladder rungs are limited** | 3–7 slots per category in memory — fight for one |
| **Name the category** | If you can't be first, **name** the subcategory you lead |

**Schwartz link:** Stage 1–2 = direct promise on ladder. Stage 3+ = new ladder (mechanism category).

**Blue Ocean link:** New category = new ladder — don't climb the old one.

## Core Positioning Moves

### 1. Against the leader (reposition)

Don't claim superiority — **reframe the leader's strength as weakness.**

| Pattern | Example logic |
|---|---|
| **Un cola** | Leader owns "cola" — you own "uncola" |
| **Not a computer** | Leader = complex — you = simple |
| **Anti-guru** | Leader = hype — you = proof |

**Carlton polarity:** Enemy must be an **idea or category**, not a person.

### 2. Own one word

| Rule | Detail |
|---|---|
| One word per brand | Volvo = safety · FedEx = overnight · Domino's = delivery |
| Word must be credible | Can't own "quality" — everyone claims it |
| Word must be defensible | Mechanism + proof stack supports the word |
| Test | *When they hear [word], do they think of you only?* |

### 3. Sacrifice (focus)

| Sacrifice | Why |
|---|---|
| **Product line** | Multiple messages = no message |
| **Target market** | Smallest viable audience (Godin) before scale |
| **Constant change** | Consistency builds the word (Ogilvy alignment) |
| **Features** | Lead with position, not spec sheet |

### 4. Category creation

**The ultimate Ries move:** Don't compete — **define the game.**

| Step | Action |
|---|---|
| Name the category | "Intent-Based Branding," "Magnetic Marketing" |
| Name the problem | What the old category failed at |
| Be first teacher | Own education in the new category |
| Become synonymous | Category word = your brand |

**Celebrity Layer 1:** Category claim = Ries positioning in personal brand form.

## 22 Laws (Architect-Operational Subset)

| Law | Copy/brand action |
|---|---|
| **Expansion** | Growth widens brand — resist line extension in copy |
| **Contraction** | Narrow focus strengthens — one avatar, one promise |
| **Publicity** | Birth of brand = news — launch as category event |
| **Advertising** | Maintenance after position won — not birth |
| **Word** | One word in mind — repeat in every asset |
| **Credentials** | Real leadership proof — category creator, not claimant |
| **Quality** | Perception of quality follows position — price/place signal |
| **Category** | Brand is category proxy — "X for Y" framing |
| **Name** | Short, memorable, suggestive — mechanism names count |
| **Extensions** | Disaster for focus — separate brands for separate ladders |
| **Fellowship** | Welcome competition in **your** new category — validates category |
| **Generic** | Never become generic word — Kleenex risk |
| **Company** | Customer thinks brand — not corporate parent |
| **Subbrands** | Subbrand dilutes — one face per ladder |
| **Siblings** | Different ladders = different brands |
| **Shape** | Visual distinctiveness (Ogilvy overlap) |
| **Color** | Own a color in category when possible |
| **Border** | No-border consistency — global brand feel |
| **Consistency** | Don't change the word — decades |
| **Change** | Rare reposition only — with news hook |
| **Mortality** | Brands die — kill losers, don't extend |
| **Singularity** | Most important law — **one word, one slot** |

## Positioning Statement (Ries Format)

```
For [target who can't get result with old category],
[Brand] is the [new category]
that [one-word benefit / owned term]
because [reason-why / mechanism proof].
```

**Not a tagline** — internal strategy doc. Copy derives from this.

## Ries Checklist

- [ ] One word identified (credible, defensible, ownable)
- [ ] Category named (new or subcategory)
- [ ] Sacrifice list — what we refuse to be
- [ ] Ladder map — leader, open rung, our slot
- [ ] No line-extension confusion in copy
- [ ] Reposition angle if #2 (not "better than")
- [ ] Mechanism term supports owned word
