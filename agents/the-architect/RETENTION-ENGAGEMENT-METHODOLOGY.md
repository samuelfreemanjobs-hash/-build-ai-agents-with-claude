## Gamification & Loyalty Program Design

### Core mechanics

| Mechanic | Job | Example |
|---|---|---|
| **Points** | Reward actions | Purchase, referral, review, login streak |
| **Tiers** | Status + ascension | Bronze → Silver → Gold → VIP |
| **Badges** | Achievement recognition | "First referral," "30-day streak" |
| **Streaks** | Habit formation | Daily login, weekly content consume |
| **Leaderboards** | Social competition | Top referrers this month |
| **Challenges** | Time-bound engagement | "7-day implementation sprint" |

### Loyalty program architecture

```
EARN (actions) → ACCUMULATE (points/tiers) → REDEEM (rewards) → ASCEND (backend offer)
```

### Reward types (align to margin)

| Reward | Cost to you | Perceived value |
|---|---|---|
| Exclusive content | Low | High |
| Community access | Low | High |
| Discount on upsell | Medium | High |
| 1:1 call | High | Very high |
| Physical swag | Medium | Medium |

### Gamification copy zones

- Progress bars: "You're 80% to Gold — one referral away"
- Milestone emails: celebration + next challenge
- In-app: streak counter + loss aversion ("Don't break your 12-day streak")

**Metric:** Redemption rate, tier progression, referral K-factor lift.

## Crisis PR & Brand Defense Protocol

### Crisis types & response frames

| Crisis | First 24h move | Message frame |
|---|---|---|
| **Product delay** | Acknowledge + new date + compensation | Transparency + over-deliver later |
| **Service outage** | Status page + ETA + updates | "We own it" + fix timeline |
| **Negative viral review** | Respond publicly (once) + take offline | Empathy + resolution path |
| **Data/privacy incident** | Legal review + mandatory disclosure | Facts only; no speculation |
| **Bad press** | Statement + proof counter-narrative | Preeminence — advocate for customer |
| **Founder controversy** | Separate brand from person if needed | Values restatement |

### Crisis communication template

```
1. ACKNOWLEDGE — what happened (facts only)
2. EMPATHIZE — impact on customer
3. ACTION — what we're doing now
4. TIMELINE — when they'll hear next
5. REMEDY — what customer gets
6. COMMITMENT — how we prevent recurrence
```

### What NOT to do

- Blame customers or employees publicly
- Delete negative comments (unless spam/abuse)
- Fake reviews or astroturf
- Over-promise fix timelines

## Cross-Cultural & Localization Engine

### Localization diagnostic (before translate)

| Dimension | Question |
|---|---|
| **Market** | Country, language variant (US vs UK vs AU English) |
| **Awareness** | Same Schwartz stage or different? |
| **Status symbols** | What signals success locally? |
| **Humor** | Translate or replace? (often replace) |
| **Taboos** | Color, gesture, religious, political |
| **Proof** | Local case studies required? |
| **Compliance** | GDPR, local ad law, health claims |
| **Payment** | Local currency, methods, trust badges |

### Copy adaptation rules

| Element | Rule |
|---|---|
| **Headlines** | Re-write, don't literal translate — re-run Caples test |
| **Idioms** | Replace with local equivalent |
| **Numbers** | Local currency, date format, units |
| **Social proof** | Local faces, local brands |
| **CTAs** | Local urgency norms (some cultures dislike hard close) |
| **Guarantees** | Legal validity per jurisdiction |

### Localization workflow

```
1. SOURCE audit — extract claims, idioms, cultural refs
2. MARKET diagnose — awareness, sophistication, taboos
3. TRANSCREATE — native copywriter quality rewrite
4. COMPLY — local regulatory scan
5. QA — native reviewer or labeled assumption
```

**Output:** Side-by-side source + localized blocks per market.
