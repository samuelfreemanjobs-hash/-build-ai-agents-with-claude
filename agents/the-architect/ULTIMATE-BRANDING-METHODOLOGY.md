## The Six-Layer Ultimate Brand Stack

Build in order. Skip a layer → commodity.

```
6. PREEMINENCE  — fiduciary advocate (Abraham)
5. MAGNETISM    — attract ideal / repel wrong (Kennedy)
4. TRIBE        — permission + movement (Godin)
3. IMAGE        — personality + big idea (Ogilvy)
2. POSITION     — one word + category (Ries)
1. PROOF CORE   — substance that survives hype (Halbert/Hopkins)
```

**Layer 0 (foundation):** Halbert starving crowd + Hopkins specificity — **no brand saves a bad offer.**

### Layer 1 — Position (Ries)

- One word · one category · sacrifice list
- New ladder or reposition leader
- Mechanism name supports word

### Layer 2 — Image (Ogilvy)

- Big idea (5–20 year durable)
- Personality spec: voice, visual, character, ritual
- Specific facts > superlatives

### Layer 3 — Tribe (Godin)

- Smallest viable audience
- Purple Cow angle (measurable)
- Permission path · manifesto · exclusion

### Layer 4 — Magnetism (Kennedy)

- Message × Market × Media aligned
- PAS in brand voice
- 10 Questions answered for brand promise

### Layer 5 — Permission (Kern)

- IBB: pre-frame → indoctrinate → convert
- Results in Advance before pitch
- Core Identity — who tribe becomes

### Layer 6 — Preeminence (Abraham)

- Trusted advisor, not vendor
- N×V×F — brand moves which lever?
- Total risk reversal on brand promise

**Celebrity Building** stacks on Layers 1–4 for stage 5 markets — person embodies position + tribe.

## The 5P Brand Conversion Loop (Architect Original)

Continuous loop — not a one-time rebrand:

```
POSITION → PERSONIFY → PERMIT → PROVE → PROFIT → (repeat)
```

| P | Master | Job | Metric |
|---|---|---|---|
| **Position** | Ries | Own word + category | Search volume on owned term; recall test |
| **Personify** | Ogilvy | Consistent personality every touch | Brand audit score; voice consistency |
| **Permit** | Godin + Kern | Gift → opt-in → anticipation | List growth; open rate; permission depth |
| **Prove** | Hopkins + Cialdini | Stack proof behind promise | Conversion rate; testimonial velocity |
| **Profit** | Kennedy + Abraham | Monetize without breaking trust | CAC:LTV; N×V×F movement |

**Galactic integration:** Schwartz diagnoses Position · Carlton executes Personify+Prove copy · Info-Product structures Profit offer.

## The Brand Conversion Audit (Improved Purple Cow Test)

Every brand asset must pass **three gates**:

### Gate 1 — Ries (Ownable?)

- [ ] Reinforces **one word**
- [ ] Clear category slot
- [ ] Sacrifice visible — not for everyone

### Gate 2 — Ogilvy + Schwab (Deposit + Flag?)

- [ ] Consistent personality
- [ ] Headline **selects** reader + **rewards** reading
- [ ] Specific, intelligent, not insulting

### Gate 3 — Godin (Remarkable + Permission?)

- [ ] Worth remarking — screenshot/quote test
- [ ] Serves SVA — exclusion clear
- [ ] Earns or deepens permission — not raw interruption

**Fail any gate → revise before ship.**

## Voice: One Brand, One Author

Ultimate Branding does **not** create multiple brand voices.

| Layer | Affects |
|---|---|
| Position, Tribe, Magnet | **What** you say and **who** you exclude |
| Image, Personify | **How** you say it — consistently |
| The Architect voice | **Constant** — cinematic, peer, precise |

Sub-brands (Ries law) = separate projects, separate briefs — not modes within one piece.
