## Webinar & Live Event Show-Up Maximizer

### Registration funnel

| Stage | Asset | Conversion job |
|---|---|---|
| **Registration LP** | Headline + 3 bullets + date/time + speaker proof | Opt-in + calendar add |
| **Thank you** | Calendar link + "add to phone" + pre-webinar homework | Commitment escalation |
| **Confirmation email** | What to expect + one prep action | Reduce no-show |
| **Reminder sequence** | Email + SMS (see table below) | Show-up rate |

### Reminder loop (show-up protocol)

| Timing | Channel | Message frame |
|---|---|---|
| **Immediately** | Email | "You're in" + calendar + homework link |
| **24h before** | Email | Story tease + "bring a notebook" |
| **1h before** | Email + SMS | "Starting soon" + direct link |
| **15 min before** | SMS | "We're live in 15 — join early for bonus" |
| **At start** | SMS | "We're live NOW — [link]" |
| **15 min late** | Email | "Replay available 24h only" (if true) |

**Target:** 30–50%+ live show rate (varies by list warmth).

### Pre-webinar homework (engagement assets)

- 3-question worksheet (surfaces pain before pitch)
- "Rate yourself 1–10 on [problem]" — self-diagnosis
- Optional community post: "What do you want answered live?"

**Job:** Sunk cost + active participation → higher stay rate + conversion.

### Live webinar structure

```
0–5 min    Welcome + housekeeping + future pace outcome
5–15 min   Story + problem agitation (bigger mice)
15–35 min  Mechanism + teaching (3 pillars max)
35–45 min  Proof stack + case studies
45–55 min  Offer + stack + guarantee + CTA
55–60 min  Q&A + final CTA + true deadline
```

### Post-webinar replay scarcity

| Asset | Spec |
|---|---|
| **Replay email** | 24–72h window (true); segment non-attendees |
| **Cart close sequence** | 3 emails: reminder, objection, final call |
| **No-show sequence** | Replay + "you missed X" + extended deadline (if offered) |

## Affiliate & JV Partner Launch Packs

Turn-key materials so partners promote without thinking.

### JV pack manifest

| Asset | Spec |
|---|---|
| **Partner brief** | Offer summary, commission, dates, rules |
| **Swipe emails** | 5–7 pre-written (story, proof, urgency, last call) |
| **Social posts** | 10+ variants (X, LinkedIn, IG caption) |
| **Ad scripts** | 3 short-form if paid allowed |
| **Leaderboard rules** | Prizes, tracking, deadline |
| **Partner bonus stack** | Exclusive bonus for partner's list only |
| **Affiliate graphics** | Sizes spec + copy overlays |
| **FAQ for partners** | Links, tracking, compliance |

### Partner email swipe structure

```
Email 1: Personal story + why promoting
Email 2: Mechanism deep-dive
Email 3: Case study / proof
Email 4: Objection handler
Email 5: Cart open
Email 6: Scarcity (true)
Email 7: Last chance
```

**Compliance:** Partners must use provided disclaimers; no income claims beyond approved copy.

## Product Launch Formula (PLF) Sequence Engine

4-part Pre-Launch Content (PLC) before cart open:

### PLC video architecture

| Part | Title frame | Job | Length |
|---|---|---|---|
| **PLC 1 — The Opportunity** | "Why now" + market shift | Channel mass desire; name enemy | 15–25 min |
| **PLC 2 — The Transformation** | Point A → Point B | Dream outcome + identity | 15–25 min |
| **PLC 3 — The Experience** | Mechanism + teaching | Proof it works; quick win demo | 20–30 min |
| **PLC 4 — The Offer** | Grand Slam reveal | Stack, guarantee, cart tease (may open after) | 20–30 min |

### PLC release cadence

| Day | Release | Email job |
|---|---|---|
| **D-7** | PLC 1 live | "Watch before it comes down" |
| **D-5** | PLC 2 live | Homework + comment engagement |
| **D-3** | PLC 3 live | Case study + social proof push |
| **D-1** | PLC 4 live | Cart opens tomorrow (or tonight) |
| **D0** | Cart open | Full launch sequence fires |
| **D+3** | Cart close | True deadline |

### PLC script beats (per video)

```
1. Hook — pattern interrupt + open loop
2. Story — peer bonding (Carlton)
3. Teach — one framework piece (not full dump)
4. Proof — case study or demo
5. Cliffhanger — "In PLC 2 I'll show you…"
6. CTA — watch next / comment / homework
```

**Sideways sales letter:** PLC emails can stand alone for non-video buyers (`FUNNEL-ARCHITECTURE-METHODOLOGY.md`).
