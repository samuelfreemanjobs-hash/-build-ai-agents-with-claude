## The Haines Hierarchy

```
1. HEADLINE        — if it fails, nothing else is read (4 chapters worth of obsession)
2. SUPERSCRIPT     — lead-in above main headline (free offers, pattern interrupt)
3. SUBSCRIPT       — follow-on under headline (intensify curiosity)
4. OPENING         — first paragraph earns paragraph two
5. BODY            — reason-why + story; fast draft; relate to headline promise
6. BULLETS         — blind bullets; curiosity > raw self-interest (Halbert private lesson)
7. PROOF           — testimonials + 16+ proof forms; rules for placement
8. OFFER           — irresistible stack; guarantees that slash refunds
9. CLOSE           — order form, coupon, ordering instructions
10. P.S.           — second ad; up to 300% bump; 8 types
```

**Architect rule:** Never skip sequence. Diagnose which element failed before rewriting the whole piece.

## Core Principle: Headline First (Non-Negotiable)

> *"If you don't get the headline right... nothing else matters. Nada. Zilch."*

| Truth | Application |
|---|---|
| Headline is the ad | 80% of success (Halbert/Caples alignment) |
| No headline buy-in = no body read | Fix headline before body copy |
| Test headline before spend | 26-word self-test (see template) |
| Bump winners 2–3× | One-word changes, superscript/subscript layers |

Haines spent **four full chapters** on headlines before body copy — that ratio is the lesson.

## Four Crucial Headline Elements

Every great headline infuses **at least one, preferably two or more** elements that strike basic human nature (unchanged since recorded history):

| # | Element | DR mapping | Example move |
|---|---|---|---|
| 1 | **Self-interest** | Caples / Victor Schwab | What's in it for me — plain benefit |
| 2 | **News** | Hopkins / Caples | New, discovered, announcing, breakthrough |
| 3 | **Curiosity** | Enquirer / Buzzhead | Open loop, gap, secret, hidden |
| 4 | **Quick-and-easy** | Caples | Fast, simple, lazy man's way, without |

**Headline test question (trim the fat):** *Would I read this if I didn't care about the product?* Tighten until yes.

## Headline Shortcut Arsenal

### Three shortcut formulas (when you need a winner NOW)

Use Caples types as Haines shortcuts — write in one-tenth the time:

| Formula | Structure |
|---|---|
| **How-to** | How to [desired outcome] [without objection / in timeframe] |
| **Question** | Do you make these mistakes in [topic]? |
| **Story** | They [ridiculed] when I [action] — but when I [result]… |

### Greatest headline/opening combo (almost never fails)

Caples story headline + immediate scene in opening paragraph:

```
[Social humiliation or doubt] + [but/when] + [reversal tease]
→ Opening paragraph drops reader into the moment
```

### Ethical "cheat" (swipe structure)

1. Find proven headline in swipe file / memory / Kennedy-Kern corpus
2. Extract **structural move** — not words
3. Swap niche, avatar, mechanism
4. Run fresh-eyes test

**Architect:** `SWIPE-FILE.md`, `memory/digest.md`, `swipes/kennedy-kern/`

### 1,000% odds boost

Write **25+ headline variants** before picking (Caples/Haines alignment). Haines: increases odds of winner by 1,000%.

### Seven sources of winning headlines

| Source | Use |
|---|---|
| Tabloids (Enquirer, etc.) | Curiosity, identity, scandal frame |
| Classic DR swipe files | Proven structure |
| Competitor mail that repeats | Someone is making money |
| Reader's Digest covers | Clarity, benefit, curiosity |
| Direct response websites (swiped.co, etc.) | Modern controls |
| Your memory / daily learn | Recent patterns |
| Kennedy/Kern email corpus | Email subject architecture |

### Formatting for maximum response

| Element | Guidance |
|---|---|
| Font | Readable, often serif for print; contrast for digital |
| Size | Headline must dominate — visual stop |
| Length | Long enough for complete thought; short enough for one glance |
| Color | Test; P.S. signature color matters (responsive ink in print) |
| Layout | Headline is not body — white space, isolation |

## Superscript & Subscript (Pre-Headline Layers)

| Layer | Job | When |
|---|---|---|
| **Superscript** | Lead-in above main headline | Free offers, pattern interrupt, qualifier |
| **Subscript** | Intensify under headline | Deepen curiosity, news, specificity |

**Rules:** "Rules are practically useless" — preferences beat rigid formulas. Model winners from three world-class marketers (Halbert, Caples, Carlton patterns).

### Salutations (only two types)

| Type | When |
|---|---|
| **"Dear Friend"** | Default DR — A-Pile personal |
| **"Dear [Name]"** | Personalization when list supports it |

Avoid corporate, stiff, or clever salutations.

### Opening paragraph

| Guideline | Detail |
|---|---|
| Deliver headline promise | Body must cover ass on headline claim |
| Avoid wrong questions | Questions in headline/opening often hurt — if used, only self-implicating type ("Do you make these mistakes…") |
| Reader's Digest exercise | Study RD openings for clarity and pull (Caples legacy) |
| Model 25 openings | Keep swipe of opening paragraphs by type |
| Halbert's favorite opening | Study best-ever Halbert open — scene + tension (see `HALBERT-METHODOLOGY.md`) |

## Body Copy Architecture

### Draft discipline

| Rule | Why |
|---|---|
| **First draft fast and furious** | Unconscious flow like talking to a friend |
| **Don't write slow and "thoughtful"** | Kills momentum and voice |
| **Stephen King method** | Get it down; fix later |
| **Become good by volume** | Not theory — reps + swipes |

### Reason-why + story (Halbert perfection)

Best body copy combines:
1. **Story** — scene, character, tension (involvement)
2. **Reason-why** — mechanism, logic, Hopkins specificity

Show Halbert full-page ad model: raw story → proof → offer.

### Believability moves

| Technique | Job |
|---|---|
| **Look slightly bad** | Admit flaw → reframe (Sugarman BluBlocker) |
| **Hopkins quote** | Specific facts beat superlatives — memorize |
| **Victor Schwab appeals** | Self-interest, savings, fear, comfort, pride, gain/loss six dimensions — see `VICTOR-SCHWAB-METHODOLOGY.md` |
| **Avoid assumption** | Don't assume they know what you know — instant toilet |

### Subheads

Most "expert" subhead advice sucks. Haines preferences:
- Enough to pull scanners through
- Each subhead = mini-headline with benefit or curiosity
- Napoleon/Lance Armstrong principle: **momentum** — never let energy die

### Master market in days (3 shortcut steps)

1. **Order competitor products** (Halbert: sell paper and ink)
2. **Collect every ad in the niche** — especially repeats
3. **Mine VOC** — Amazon reviews, forums, support tickets (`VOC-RESEARCH.md`)

### Three reasons they won't buy (+ X-factor)

| # | Reason | Fix in copy |
|---|---|---|
| 1 | Don't believe you | Proof stack, reason-why, testimonials |
| 2 | Don't believe it works for them | Identification, case studies like them |
| 3 | Don't believe they can do it | Simplify, guarantee, demo |
| **X** | Hidden objection | Dig for real reason — often identity, shame, timing |

**Uncover hidden objections:** Survey, sales calls, refund reasons, "almost bought" feedback.

### Story selling (3 best ways)

1. **Personal story** — I was where you are
2. **Client story** — someone like them transformed
3. **Discovery story** — how the mechanism was found (reduces skepticism on big claims)

### #1 deal-killing mistake (years 1–5)

**Feature-dumping before desire is built** — or breaking headline promise in body. Fix: slippery slide from headline promise; emotion before specs (`SUGARMAN-METHODOLOGY.md`).

### After first draft (5 things)

1. Cut **work words** (see below)
2. Fresh-eyes pass on headline
3. Bucket brigade injection
4. Two persuasion tests per line
5. Proof and objection sweep

### Work words (A-level vs B-level)

**Work words** = lazy, vague, effort-signaling copy that makes the reader work. B-level writers use them; A-level eliminates through deep thinking.

| Work word signals | Fix |
|---|---|
| "Very," "really," "things," "stuff" | Cut or replace with specific |
| Abstract nouns without scenes | Add time, place, number |
| Throat-clearing openers | Start with tension or benefit |

**Test:** Read aloud — any line that feels like homework gets rewritten.

## Bucket Brigade (Momentum Engine)

Dominant human trait: **curiosity + completion desire**. Bucket brigade words force the next line.

### How to use

Sprinkle at:
- End of paragraphs
- Before subheads
- Before bullets
- Before CTA

### Core bucket brigade phrases (use and adapt)

| Category | Examples |
|---|---|
| **Continuation** | But there's more. Here's why. Let me explain. And that's not all. |
| **Reveal** | The truth is. What happened next shocked me. Here's the secret. |
| **Turn** | However. Yet. Still. On the other hand. |
| **Specificity** | For example. Case in point. Consider this. |
| **Urgency** | Now. Today. Before you decide. Read this first. |

**Root words for infinite variants:** And, But, Here's, Now, Why, How, What, Because

**Overlap:** Sugarman "seeds of curiosity" — same slippery slide physics.

### Cheat to world-class rhythm

**Hand-copy winning ads** in your handwriting — ingrains tempo, flow, vocabulary. Haines + Halbert shortcut to mastery.

## Killer Bullets

| Rule | Detail |
|---|---|
| **Use every bullet you can** | Bullets sell scanners |
| **Almost all blind** | Tease benefit; withhold mechanism — curiosity drives read |
| **#1 appeal (Halbert, private)** | Not self-interest — **curiosity** (fake cocaine bullet lesson) |
| **Most powerful type** | Plays on two inborn traits — curiosity + greed/loss |
| **Format for readership** | Parallel structure, rhythm, white space |
| **Write bullets first** | Often faster; defines offer architecture |

### Bullet types (complete list framework)

Benefit, curiosity/blind, fascinations, proof, how-to, warning, if-then, objection-killer.

### 9-step quick ad formula (30–45 min)

For info products especially — connect-the-dots:

1. Headline (shortcut formula)
2. Superscript/subscript if needed
3. Opening (story or problem)
4. Agitate
5. Mechanism
6. Bullets (blind stack)
7. Proof
8. Offer + guarantee
9. CTA + P.S.

## Proof & Testimonials

### Testimonial rules (never break)

| Rule | Detail |
|---|---|
| **Specific beats generic** | Numbers, results, timeframes |
| **Sounds human** | Don't over-edit grammar if authenticity sells |
| **Placement** | After claim they support — not random sidebar |
| **Minimum count** | Stack until skepticism breaks |

### 16+ proof forms (seek actively)

Testimonials, case studies, demos, before/after, credentials, media logos, third-party data, celebrity borrow, "exposed" frame, track record, comparisons, guarantees, samples, trials, certifications, volume metrics.

### Borrowed credibility

Authorities and celebrities for pennies — ethical endorsement, licensed quotes, media "as seen in."

## Offers, Guarantees & Close

### Halbert homerun secret (memorize)

**Change the offer before you change the copy** — often the fastest path from loser to monster winner (Coat-of-Arms turnaround).

### Offer levers

| Lever | Haines/Kennedy alignment |
|---|---|
| Value stack | Bonuses kill objections |
| Risk reversal | Stronger guarantee = more sales, fewer refunds |
| Contrarian offer | Opposite of 99.9% "experts" — what richest DR marketers do |
| Buy results/data | Test mindset — pay for learning |

### Guarantee types

- Money-back
- "$10 in your pocket" (you pay them if it fails)
- **Active guarantee** — dramatized, not buried in fine print
- Avoid "chicken-shit" weak language that signals distrust

### Order form / close

| Rule | Detail |
|---|---|
| **Headline on order form** | Yes — restate benefit |
| **Never two response-killer words** | (Avoid "buy" / "submit" — use "Start," "Get," "Reserve") |
| **Don't tip them off** | Halbert: don't telegraph "sales pitch" too early in package |
| **Reverse side blank** | Print discipline for mail |
| **Coupon test** | Print vs no-coupon by medium |

### P.S. (8 types — second ad)

| P.S. type | Use |
|---|---|
| Urgency/deadline | Last chance |
| Bonus reminder | What they lose |
| Proof restate | Strongest testimonial |
| Guarantee | Risk reversal |
| New benefit | Didn't fit body |
| Story kicker | One more scene |
| CTA repeat | URL/phone |
| Personality | Sign-off sincerity |

Sign with **"Sincerely"** — responsive signature color in print.
