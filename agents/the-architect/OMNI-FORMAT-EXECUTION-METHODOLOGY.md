# Omni-Format Asset Execution Methodology

**Phase 4 execution layer for The Architect.** Structural blueprints for every content format — from viral Medium articles to VSL scripts to direct mail to UI micro-copy.

**One voice.** Format changes structure; personality never changes.

**Client attraction:** Every format ships with avatar, trackable CTA, and ascension path — see `CLIENT-ATTRACTION-METHODOLOGY.md`.

---

## Omni-Format in One Sentence

> **Every format has a proven skeleton — load the blueprint, fill it with diagnosed desire and engineered offer, and ship one author voice from tweet to sales letter.**

## F-MED — Viral Medium Articles

```
1. Counter-intuitive title hook
2. Personal vulnerable story lead
3. "Aha" paradigm shift
4. 3–5 scannable tactical pillars (H2 each)
5. Emotional takeaway summary
6. Soft CTA (newsletter, lead magnet)
```

---

## F-ECOM — E-Commerce Product Descriptions

```
1. Sensory pattern-interrupt headline
2. 2-sentence lifestyle pitch
3. Bulleted "So What?" benefit list (Carlton)
4. Mechanism breakdown (stage 3+)
5. Micro-proof (review snippet, stat)
6. Direct CTA
```

---

## F-SALES — Sales Letters & Long-Form Copy

```
Full 17-step SWS (Phase 8) + 3-step offer close (Phase 9)
Template: research/CARLTON-SWS-TEMPLATE.md
```

## F-AD — Ads & Scripts (Meta, TikTok, YouTube, VSL, Podcast)

**Structure: Visual Cue + Audio VO + Text-on-Screen (TOS)**

| Timestamp | Beat |
|---|---|
| **0–3s** | Pattern-interrupt hook — visual shock, weird detail, bold claim |
| **3–15s** | Problem ID + agitation ("bigger mice") |
| **15–45s** | Solution reveal + proprietary mechanism demo |
| **45–60s** | Micro-proof + urgent CTA |

**Deliverable table:**

| Time | Visual | VO | TOS |
|---|---|---|---|
| 0–3s | | | |
| 3–15s | | | |
| etc. | | | |

| Element | Rule | Example |

| Subtext | Friction remover | "No spam · Unsubscribe anytime" |

## F-DM — Direct Mail

| Component | Job |
|---|---|
| **Outer envelope teaser** | Curiosity — never reveal offer on envelope |
| **Lift letter** | Personal P.S.-driven note |
| **Main letter** | SWS condensed |
| **Order form insert** | Frictionless response — toll-free, QR, prepaid |
| **Handwriting accents** | Authenticity signal on teaser/lift |

## F-LP — Landing Pages & Elite Web Copy

```
1. Hero: pre-head callout + benefit headline + subhead + primary CTA + trust badges
2. Pain agitation
3. Mechanism deep-dive
4. Testimonials / proof stack
5. FAQ objection-slayer
6. Sticky CTA footer
```

## F-EMAIL — Converting Email Marketing

```
1. Subject: 5–8 words, high curiosity
2. Preview text: open loop
3. Body: informal "cracking a beer" voice (Carlton bonding)
4. Single clear hyperlinked CTA
5. P.S. — second hook or urgency
```

---

## F-MAG — Magazine Articles & Editorial

```
1. Journalism deck (subhead summary)
2. Scene-setting lead
3. Authority quotes
4. Data sidebars
5. Compelling pull-quotes
6. Nuanced conclusion (no hard sell unless advertorial)
```

---

## F-BLOG — Highly Engaging Blog Posts

```
1. SEO intent hook (title + meta)
2. "Why you should care" opener
3. Table of contents
4. H2/H3 sections with custom frameworks
5. Actionable summary / TL;DR
6. Lead magnet CTA
```

---

## F-LEAD — Lead Generation Materials

| Type | Structure |
|---|---|
| **Cheat sheet** | One problem → 5–10 tactical bullets → opt-in CTA |
| **Prompt vault** | Categorized prompts + use case per prompt |
| **Resource guide** | Curated links/tools + Architect commentary |
| **Quiz** | Segmentation → personalized result → offer match |
| **ROI calculator** | Inputs → quantified pain → "here's what fixing it is worth" |

**Rule:** Solves one urgent problem immediately. Zero opt-in friction on the asset itself.

**Deep file:** `LIST-BUILDING-METHODOLOGY.md`
