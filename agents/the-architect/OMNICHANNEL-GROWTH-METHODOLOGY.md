## Platform-Specific Ad Creative Protocols

### Meta (Facebook / Instagram)

| Element | Spec |
|---|---|
| **Visual hook** | UGC-style, high contrast, face in first frame, movement in 0–1s |
| **Script lead** | Problem-agitation in casual voice — "I was today years old when…" |
| **Format** | 15s reel + 60s story variant; square + vertical crops |
| **Proof** | Screen recording, before/after, testimonial selfie |
| **CTA** | Comment trigger or DM keyword → bot/sequence |
| **Anti-pattern** | Polished corporate VO, static carousel without hook |

**Blueprint ID:** `F-AD-META`

### TikTok / Reels / Shorts

| Element | Spec |
|---|---|
| **Pacing** | Cut every 1.5–2.5s; pattern interrupt on beat drop |
| **Audio** | Trend-adjacent hook (or silence + bold TOS for contrarian) |
| **TOS timing** | Key claim on screen at 0s, mechanism at 3s, CTA at 12s |
| **Script** | Native casual — peer confession, not announcer |
| **CTA** | Link in bio / "Part 2" comment bait / stitch duet prompt |
| **Anti-pattern** | Repurposed YouTube horizontal with tiny text |

**Blueprint ID:** `F-AD-TIKTOK`

### YouTube Ads (In-Stream / Discovery)

| Element | Spec |
|---|---|
| **5-second skip interrupt** | Bold claim or visual shock before "Skip" — payoff teased not delivered |
| **Body** | Educate through mechanism — "here's why everything you tried failed" |
| **Proof** | Demo-heavy; whiteboard or screen share |
| **CTA** | Intent-focused — "watch the full breakdown" → VSL or landing page |
| **Length** | 60s hook variant + 3–6 min explainer for warm retargeting |
| **Anti-pattern** | Generic brand anthem; no mechanism by 0:15 |

**Blueprint ID:** `F-AD-YOUTUBE`

**Deliverable:** Visual + VO + TOS table per `OMNI-FORMAT-EXECUTION-METHODOLOGY.md` F-AD.

## B2B & Enterprise ABM Framework

B2B cycles involve multiple stakeholders. Map copy to **role-specific messaging**.

### Stakeholder map

| Role | Cares about | Message frame | Asset type |
|---|---|---|---|
| **Champion** | Career win, internal credibility | "Make you the hero who brought this" | Internal deck, ROI one-pager |
| **Decision Maker** | Revenue, risk, strategic fit | Executive summary + competitive moat | 1-page business case |
| **Gatekeeper** | Security, compliance, vendor vetting | SOC2, SLA, integration docs | Trust center, technical brief |
| **Procurement** | Price, terms, contract risk | TCO model, payment terms, MSA-ready | Pricing matrix, comparison sheet |
| **End User** | Daily workflow, ease | Time-to-value, UI walkthrough | Demo script, onboarding preview |

### ABM diagnostic layer (Phase 1 extension)

- [ ] Named account list or ICP firmographics
- [ ] Buying committee roles identified
- [ ] ROI model: `(revenue lift or cost save) − investment = payback period`
- [ ] Risk-mitigation arguments per role
- [ ] Multi-touch sequence: awareness → champion enablement → exec review → procurement

### B2B email sequence framework (7-touch minimum)

| Touch | Role | Goal |
|---|---|---|
| 1 | Champion | Pattern interrupt + peer proof |
| 2 | Champion | Mechanism + quick win case study |
| 3 | Champion | Internal forwardable asset (ROI calc) |
| 4 | Decision Maker | Strategic outcome + competitive angle |
| 5 | Champion | Objection pre-handle + demo invite |
| 6 | Decision Maker | Risk reversal + timeline |
| 7 | All | Clear next step + true scarcity (cohort, implementation cap) |

## Viral K-Factor & Community Growth Mechanics

### Viral coefficient

```
K = i × c

i = invitations sent per customer (or shares per user)
c = conversion rate of each invitation
```

| K value | Growth dynamic |
|---|---|
| **K < 1** | Paid/organic required; optimize i and c |
| **K = 1** | Stable; each user replaces themselves |
| **K > 1** | Viral loop; CAC collapses |

### Optimization levers

| Lever | Tactics |
|---|---|
| **Increase i** | Milestone referral prompts, shareable results, team invites, post-purchase collateral |
| **Increase c** | Frictionless invite UX, double-sided incentive, social proof on landing |
| **Reduce CAC** | Referral credits, ambassador tiers, UGC challenges, community leaderboards |

### Shareable post-purchase collateral

- Branded results cards ("I just [outcome] with [product]")
- Referral link with named reward for both parties
- Community milestone badges
- "Invite 3, unlock [bonus]" unlock mechanics

**Architect output:** When designing growth loops, calculate hypothetical K with assumptions labeled. Include in `<diagnostic_summary>`.
