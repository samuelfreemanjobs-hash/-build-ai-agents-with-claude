## First Principles

| Law | Application |
|---|---|
| **Permission over interruption** | Opt-in with anticipated value — Godin + Kern |
| **Specificity wins** | Lead magnet for one avatar, one outcome |
| **Results in Advance** | Magnet demonstrates capability before pitch |

---

## Lead Magnet Architecture

| Type | Best for | Magnet examples |
|---|---|---|
| **Checklist / cheat sheet** | Quick win seekers | "7-point audit," swipe file |
| **Template / toolkit** | Implementers | Fill-in-blank, calculator |
| **Mini-course / challenge** | Relationship builders | 3–5 day email/video |
| **Report / manifesto** | Thought leadership | Category-defining PDF |
| **Quiz / assessment** | Self-diagnosis | Score + personalized result |
| **Webinar / workshop** | High-intent | Live or evergreen registration |

**Schwartz alignment:** Magnet promise must match awareness stage — problem-aware gets pain audit; solution-aware gets mechanism preview.

**Carlton:** Sales-detective stories inside magnet copy — not brochure fluff.

## Squeeze Page Essentials

| Element | Job |
|---|---|
| Headline | One outcome in one glance |
| Subhead | Mechanism or curiosity |
| 3–5 bullets | What they get — blind where possible |
| Proof | One testimonial or stat |
| CTA | "Send me [specific thing]" |
| Friction kill | Name + email only (test phone later) |

**Victor Schwab:** Select avatar + reward reading.

| Loop type | Mechanism |
|---|---|

| **Milestone tiers** | Unlock rewards at 3, 10, 25 referrals |

## List Building Checklist

- [ ] Magnet delivers standalone value (Results in Advance)
- [ ] Avatar-specific — not generic PDF
- [ ] Squeeze page: Schwab select+reward
- [ ] Soap opera or welcome sequence mapped
- [ ] Segmentation plan post-opt-in
- [ ] Referral loop considered
- [ ] Compliance: consent clear; unsubscribe easy
- [ ] Metric: target CPL and opt-in rate defined
