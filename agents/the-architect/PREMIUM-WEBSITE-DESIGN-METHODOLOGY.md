## What $10K Website Design Means (Architect Standard)

This is **not** a template swap or "make it pretty." A $10K Architect website deliverable includes:

| Layer | $2K freelancer | $10K Architect standard |
|---|---|---|
| **Strategy** | "What pages do you want?" | Executive diagnostic + funnel map + conversion metric per page |
| **IA / sitemap** | Client guess | MECE page architecture tied to buyer journey |
| **Design** | Stock theme | Custom design system — palette, type scale, spacing, components |
| **Copy** | Lorem ipsum or client dump | Conversion copy in every zone — headlines, micro-copy, CTAs (one voice) |
| **Conversion** | One contact form | Funnel-integrated CTAs, proof stacks, objection zones, ascension paths |
| **Mobile** | Shrunk desktop | Mobile-first wireframes with thumb-zone CTAs |

**Pricing anchor:** Position as value-based — ROI of one additional high-ticket client per month often exceeds $10K. (`PRICING-MASTER-METHODOLOGY.md`)

## The 8-Phase Website Build Pipeline

```
1. DISCOVER   — Brief, avatar, offer, metric, competitors, brand audit
2. STRATEGIZE — Funnel role of site; primary + secondary conversions
3. ARCHITECT  — Sitemap, page goals, user flows, CTA map
4. SYSTEMIZE  — Design tokens: color, type, spacing, components
5. WIREFRAME  — Page-by-page zones (desktop + mobile)
6. COPY-ZONE  — Headlines, body, micro-copy, proof per zone (Architect voice)
7. SPEC       — Interactions, animations, forms, integrations, SEO
8. HANDOFF    — Dev-ready package + client attraction audit
```

## Phase 1–2: Discovery & Strategy

### Discovery questions (mandatory)

| Area | Questions |
|---|---|
| **Business** | Offer, price point, LTV, primary revenue model |
| **Avatar** | Who converts? Awareness + sophistication stage |
| **Conversion** | Primary CTA (book call, buy, apply, opt-in)? Secondary? |
| **Proof** | Case studies, logos, stats, demos available? |
| **Brand** | Existing identity or build from scratch? Ries word? |
| **Competition** | 3 competitor sites — what to beat, what to avoid |
| **Tech** | Platform (Webflow, WordPress, custom, Shopify)? Integrations? |

### Site archetypes (pick one primary)

| Archetype | Best for | Core pages |
|---|---|---|
| **High-ticket service** | Consultants, agencies, coaches $3K+ | Home, About/Story, Services, Case Studies, Process, Book Call |
| **Info product / course** | Courses, memberships | Home, Program, Results, About, Checkout/LP |
| **SaaS** | Software subscriptions | Home, Features, Pricing, Demo, Docs/Resources |
| **Personal brand / authority** | Speakers, authors, celebrities | Home, Story, Speaking/Media, Resources, Work With Me |
| **E-commerce** | Physical/digital products | Home, Collection, PDP, Cart, About, Support |
| **Launch / funnel hub** | Campaign-specific | Squeeze, Sales, Thank You, Upsell, Member portal |

**Funnel link:** Map site pages to `TRAFFIC → CAPTURE → BELIEEF → CONVERT → ASCEND` (`FUNNEL-ARCHITECTURE-METHODOLOGY.md`).

## Phase 3: Information Architecture

### Sitemap deliverable

For each page document:

| Field | Spec |
|---|---|
| **Page name** | |
| **URL slug** | SEO-friendly |
| **Funnel stage** | Capture / Belief / Convert / Ascend |
| **Primary job** | One sentence — what this page must accomplish |
| **Primary CTA** | Trackable action + destination |
| **Proof required** | Which proof pyramid layers |
| **Exit paths** | Where user goes next (no dead ends) |

### User flow map

```
Entry (ad/organic/direct) → Landing page → [Belief pages] → Conversion → Ascension
```

Document 2–3 primary flows: cold visitor, warm referral, returning lead.

## Phase 4: Design System ($10K Differentiator)

### Design tokens

| Token | Spec |
|---|---|
| **Primary palette** | 1 dominant + 1 accent + neutrals (hex + usage rules) |
| **Typography** | Display + body families; scale (H1–H6, body, caption) |
| **Spacing** | 4/8px grid; section padding; content max-width |
| **Border radius** | Consistent rounding (premium = subtle) |
| **Shadows** | Elevation levels for cards, modals, sticky nav |

### Component library (minimum)

| Component | Conversion job |
|---|---|
| **Hero** | Pattern interrupt + headline + CTA + trust strip |
| **CTA button** | Primary / secondary / ghost variants + micro-copy |
| **Proof bar** | Logos, stats, ratings |
| **Testimonial card** | Photo + quote + result metric |
| **Case study block** | Before/after + mechanism + CTA |
| **FAQ accordion** | Objection slayer |
| **Pricing table** | Anchor/decoy tiers (`PRICING-MASTER-METHODOLOGY.md`) |
| **Lead capture** | Form + magnet + friction reducers |
| **Sticky header/footer CTA** | Persistent conversion on scroll |
| **Guarantee badge** | Risk reversal visual |

**Brand link:** Ogilvy consistency + Ries focus — one visual personality sitewide.

## Phase 5: Page Wireframes

Deliver **structured wireframe specs** — ASCII, markdown tables, or section blocks. Each page includes desktop + mobile.

### Universal page zones (F-LP extended)

```
┌─────────────────────────────────────────┐
│ STICKY NAV: logo | links | primary CTA  │
├─────────────────────────────────────────┤
│ HERO: pre-head | H1 | subhead | CTA    │
│       trust badges | hero visual spec   │
├─────────────────────────────────────────┤
│ PROBLEM: agitation (bigger mice)        │
├─────────────────────────────────────────┤
│ MECHANISM: how it works (3–5 steps)     │
├─────────────────────────────────────────┤
│ PROOF STACK: social → demo → case study │
├─────────────────────────────────────────┤
│ OFFER / SERVICES: stack or tier cards     │
├─────────────────────────────────────────┤
│ OBJECTIONS: FAQ or comparison table       │
├─────────────────────────────────────────┤
│ FINAL CTA: 3-step close + guarantee     │
├─────────────────────────────────────────┤
│ FOOTER: links | legal | secondary CTA   │
└─────────────────────────────────────────┘
```

### Wireframe spec table (per section)

| Zone | Layout | Visual spec | Copy zone (draft) | CTA | Mobile notes |
|---|---|---|---|---|---|
| Hero | 60/40 split | Full-bleed image + overlay | H1, subhead, pre-head | Button + subtext | Stack vertical; CTA thumb-zone |

**Carlton theatre:** White space, power subheads, eye relief — no wall-of-text homepages.

## Phase 6: Copy-Zone Integration

The Architect **writes conversion copy into every zone** — not placeholder lorem.

| Zone | Copy deliverables |
|---|---|
| Hero | Pre-head, H1 (Caples-tested), subhead, CTA label + subtext |
| Sections | H2s, body, bullets (So What? extracted) |
| Proof | Testimonial pull quotes, stat callouts |
| Forms | Field labels, button text, privacy line |
| Meta | Title tag, meta description (SEO + curiosity) |

Run `EDITOR-PASSES.md` + pre-delivery 100-pt score on all customer-facing copy zones.

## Phase 7: Technical & Performance Spec

| Area | $10K standard |
|---|---|
| **Core Web Vitals** | LCP < 2.5s target; specify image optimization |
| **Mobile-first** | Breakpoints: 375, 768, 1024, 1280+ |
| **SEO** | H1 per page, schema markup notes, internal linking map |
| **Accessibility** | WCAG AA contrast; focus states; alt text guidance |
| **Integrations** | CRM, calendar, email, analytics, pixels — form field map |
| **Animations** | Subtle scroll reveals, CTA hover — spec don't overdo |

## Phase 8: Dev Handoff Package

Every $10K website job ships:

1. **Strategic diagnostic summary** — avatar, funnel role, metrics
2. **Sitemap + user flows**
3. **Design system doc** — tokens + component library
4. **Page wireframes** — all pages, desktop + mobile
5. **Copy master doc** — all zones, one voice
6. **Micro-copy table** — every button, form, error state
7. **Interaction notes** — sticky nav, modals, accordions
8. **SEO + performance checklist**
9. **Client Attraction Note** — per-page CTA + metric
10. **Quality score** — rubric + pre-delivery audit
