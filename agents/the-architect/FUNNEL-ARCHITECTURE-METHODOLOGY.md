## Funnel Selection Matrix

| Architecture | Primary goal | Best when | Key metrics |
|---|---|---|---|
| **Lead magnet / squeeze** | List growth | Cold traffic; new market entry | Opt-in rate, CPL |
| **Tripwire + bump + OTO** | CAC liquidation | Paid traffic; prove offer | Front-end ROAS, bump take rate |
| **VSL / webinar / application** | High-ticket conversion | $500+ offers; complex sale | Show rate, app rate, close rate |
| **PLC / sideways sales letter** | Warm launch | Owned list; story-led | PLC completion, cart conversion |
| **Evergreen VSL** | Scalable cold | Proven offer; paid scale | CPA, EPC, LTV:CAC |
| **Subscription / membership** | Retention & LTV | Continuity revenue | Churn, MRR, activation rate |

**Kern GOO:** If funnel fails, diagnose **one stage** — don't rebuild everything.

## Universal Funnel Stages

```
TRAFFIC → CAPTURE → BELIEF → CONVERT → ASCEND → RETAIN
```

| Stage | Job | Common leak |
|---|---|---|
| **Traffic** | Right audience, right intent | Wrong targeting |
| **Capture** | Opt-in or tripwire purchase | Weak hook, friction |
| **Belief** | Mechanism + proof | No story, thin proof |
| **Convert** | Core offer close | Weak stack, no urgency |
| **Ascend** | OTO / upsell / high-ticket | Missing backend |
| **Retain** | Onboarding, churn fight | No time-to-value |

**SaaS/CRO deep file:** `SAAS-RETENTION-CRO-METHODOLOGY.md` — dunning, activation triggers, cancellation deflection, quantitative drop-off troubleshooting matrix.

## Micro-Copy Wireframe (Every Funnel)

Map before writing. Each node gets: headline, subhead, proof, CTA, friction audit.

### Capture page (squeeze / tripwire)

| Element | Spec |
|---|---|
| Pre-head | Qualifier: "For [avatar] who…" |
| Headline | Schwartz-aware hook; Victor Schwab select+reward |
| Bullets | 3–7 blind fascinations or benefits |
| Proof | Micro-testimonial, number, or demo |
| Form | Minimum fields; single CTA |
| Trust | Badges, privacy, sample if applicable |

### Sales / VSL / webinar page

| Element | Spec |
|---|---|
| Headline + lead | Carlton theatre + bonding |
| Problem agitation | Bigger mice — Kennedy PAS |
| Mechanism | Named system (Schwartz 3+) |
| Proof stack | Story → stat → authority |
| Offer reveal | 3-step offer (Phase 8) |
| Value stack | Bonuses mapped to objections — `HORMOZI-METHODOLOGY.md` |
| Guarantee | Multi-tier risk reversal |
| CTA blocks | 2–3 throughout |
| FAQ | Top 5 objections |

### Checkout architecture

| Element | Spec |
|---|---|
| **Order bump** | Complementary; one-click |
| **OTO1** | Core ascension — highest intent |
| **OTO2** | Implementation accelerator |
| **Downsell** | Payment plan or lite version |
| **Confirmation** | Thank-you + immediate second offer (Halbert ~20%) |

## Email Lifecycle Architecture

### Soap Opera Sequence (days 1–7)

| Day | Job | Tone |
|---|---|---|
| 1 | Set the stage — backstory, empathy | Bonding |
| 2 | High drama — wall hit | Agitation |
| 3 | Epiphany — discovery of solution | Mechanism tease |
| 4 | Hidden benefits | Proof |
| 5 | Urgency + social proof | Turbulence |
| 6 | Objection handling | Salesmanship |
| 7 | Open cart / hard CTA | Close |

**Kern:** Same voice as sales page — no tone shift at pitch.

### Cart abandonment (3–5 emails)

| # | Angle |
|---|---|
| 1 | Reminder + benefit restate |
| 2 | Objection crusher |
| 3 | Social proof |
| 4 | Urgency (if true) |
| 5 | Last chance + guarantee |

### Onboarding / churn reduction

| Email | Job |
|---|---|
| Welcome | One quick win in 24h |
| Day 2–3 | Activation milestone |
| Day 7 | Success story from peer |
| Day 14 | Advanced tip + ascension tease |
| Pre-renewal | ROI recap + retention offer |

## Friction Removal Checklist

- [ ] Form fields minimized
- [ ] Mobile checkout tested
- [ ] Trust badges at payment
- [ ] Micro-proof near CTA
- [ ] Single primary action per screen
- [ ] Load speed acceptable
- [ ] Guarantee visible pre-CTA
- [ ] Price anchor before reveal
