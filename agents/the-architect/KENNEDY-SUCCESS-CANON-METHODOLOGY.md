## 1. Napoleon Hill — Definite Chief Aim

**Skills to model:**

| Principle | Operator behavior |
|---|---|
| **Definite Chief Aim** | One sentence: what Persuasion Mechanics becomes in 12 months — written, read daily |
| **Burning desire** | Factory runs because the catalog vision is non-negotiable |
| **Faith / auto-suggestion** | Act as Chief Persuasion Architect before external proof catches up |
| **Specialized knowledge** | AI agents + DR + systems — stack expertise, don't generalize |
| **Organized planning** | `PERSUASION-MECHANICS-12-MONTH-PLAN.md` is the organized plan |
| **Mastermind** | Cohort, JV partners, factory agents = synthetic mastermind |
| **Persistence** | 10 books in 12 months — persistence as system, not mood |

**Daily Hill practice (2 min):** Read definite aim aloud. One organized-plan action before inbox.

**Copy link:** Hill's desire → Schwartz mass desire (external market). Internal aim powers external message.

## 2. Maxwell Maltz — Psycho-Cybernetics

**Kennedy's "absolute favorite" for mindset.**

**Skills to model:**

| Principle | Operator behavior |
|---|---|
| **Self-image thermostat** | You ship as a **published authority** — because PM-000 is live, act from that identity |
| **Success mechanism** | Brain as goal-seeking system — define target (chapter shipped, list size) and let RAS find path |
| **Failure mechanism** | Cut "I'm not ready" loops — ship at rubric 8+, revise in public if needed |
| **Mental rehearsal** | Visualize launch day, cohort fill, backend call booked — before writing CTA |
| **21-day habit** | Factory daily chapter = habit installation, not inspiration |
| **Relaxation under pressure** | OPEN months and launches — calm operator (Powers fun posture + Maltz calm mechanism) |

**Daily Maltz practice (3 min):** 60-second mental movie of today's desired outcome (one shipped asset + one list action). Then execute.

**Powers link:** Powers first scaled *Psycho-Cybernetics* — identity transformation books are **core catalog category** for Wilshire/PM.

## 3. Robert Ringer — Winning Through Intimation

**Skills to model:**

| Principle | Operator behavior |
|---|---|
| **Reality over wishful thinking** | GOO diagnostic — see funnel as it is, not as hoped |
| **Position of strength** | Premium pricing; don't discount from weakness |
| **Leverage awareness** | Who needs the deal more? JV, client, partner terms |
| **Don't be intimidated** | Enterprise/industrial buyers respect strength — not apology copy |
| **Document everything** | Proposals, SOWs, partner agreements — Ringer's paperwork discipline |

**Daily Ringer check:** Before any deal: *Am I negotiating from strength or fear?*

**Copy link:** Kennedy repel wrong fits = Ringer don't beg.

## 4. W. Clement Stone — Success System That Never Fails

**Skills to model:**

| Principle | Operator behavior |
|---|---|
| **PMA (Positive Mental Attitude)** | Operator default — Powers "having a good time" + Stone PMA |
| **Do It Now** | Factory chapter today, not "when inspired" |
| **Go the extra mile** | Second editor pass, extra headline variants, bonus stack for partners |
| **Seed in every setback** | Bad launch → GOO fix; refund → survey + downsell |
| **Goal cards + daily action** | Monthly metric on card; daily measurable action toward it |

**Daily Stone practice:** First work block = highest-value revenue action (Do It Now). PMA reframe on one obstacle.

**Kennedy link:** Stone's follow-up intensity = Kennedy multi-touch obsession.

## Integrated Daily Operator Stack (15 minutes)

| Min | Practice | Source |
|---|---|---|
| 0–2 | Read **Definite Chief Aim** (Hill) | Purpose |
| 2–5 | **Mental rehearsal** of today's win (Maltz) | Self-image |
| 5–6 | **Do It Now** — start factory/highest $ task (Stone) | Action |
| 6–8 | **PMA reframe** one obstacle (Stone) | Attitude |
| 8–10 | **Strength check** on today's deal/ask (Ringer) | Leverage |
| 10–12 | **Thick face** — one polarizing or decisive move scheduled (Chu) | Courage |
| 12–15 | **Abundance check** — one premium action (Wilde) | Wealth posture |

Then: **Powers mail-order work** — list, test, ship, ask.
