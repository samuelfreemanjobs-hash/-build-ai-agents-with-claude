# Info-Product Architecture Engine

Dedicated Engine III of the Galactic Master System. Architects **courses, programs, memberships, reports, and coaching offers** as integrated revenue machines — not copy bolted onto random module lists.

**One voice** — product architecture informs copy; copy maps back to product spine. Not a separate mode.

**Paired engines:** Schwartz (what market will buy) · Carlton (how to sell it) · This file (what to build)

---

## Info-Product in One Sentence

> **Diagnose desire, ladder the transformation, spine the curriculum, name the mechanism, stack the offer, map the funnel, then write Carlton copy where every bullet sells a module and every module delivers one install.**

---

## The Info-Product Thesis

| Myth | Reality |
|---|---|
| "Build the course, then write the sales page" | **Bullets define architecture** — write fascinations first, modules second (Haines) |
| "More content = more value" | **Installation beats information** — one 10-min win per module (Pagan) |
| "Price on hours of video" | **Price on transformation + access** — outcome and proximity (Kern) |
| "Launch is the sales page" | **Launch is a funnel** — PLC, webinar, or challenge sequence (Kern/Kennedy) |
| "Backend is optional" | **LTV is the business** — ascension path designed day one (Abraham N×F) |

**Halbert foundation:** You can't multiply zeros — prove the offer (competitor ads running) before sweetening.

## Nine-Phase Architecture Pipeline

Run in order. Save outputs to `research/INFO-PRODUCT-ARCHITECTURE-TEMPLATE.md`.

### Phase 1 — Market Intelligence

**Job:** Validate starving crowd and map competitive landscape.

| Step | Action | Source |
|---|---|---|
| Competitor ad sweep | Collect every ad, sales page, VSL in niche | Halbert Step 1–2 |
| Buy / analyze top offers | Extract nuggets to index cards | Halbert Step 3 |
| Schwartz diagnosis | Desire, awareness, sophistication | Engine I |
| Gap analysis | What competitors lack; your super-product angle | Halbert Step 4–5 |
| VOC mining | Exact phrases, objections, failed solutions | `VOC-RESEARCH.md` |

**Output:** Market map + ownable gap + proof competitors are spending (offer is viable).

### Phase 2 — Transformation Ladder

**Job:** Define the **before → after** journey in measurable rungs.

| Rung | Field |
|---|---|
| **Hell** | Specific before state (scene, numbers, emotion) |
| **Rung 1** | First small win (24–72 hours) |
| **Rung 2–N** | Progressive capabilities unlocked |
| **Heaven** | Core Identity after state (Kern) — who they become |
| **Proof per rung** | What evidence shows they climbed |

**Rule:** Every module must advance **exactly one rung**. No module without a rung assignment.

### Phase 3 — Curriculum Spine

**Job:** Module architecture optimized for **belief + installation**, not content volume.

| Principle | Application |
|---|---|
| **One big idea per module** | Woodsmall chunking |
| **One install per module** | ≤10-minute action (Pagan) |
| **Named framework** | 3–7 parts they can remember |
| **Open loop between modules** | Business thriller cliffhanger |
| **Quick win first** | Module 1 = fastest result (reduces refund fear) |

**Module card (repeat per unit):**

| Field | Content |
|---|---|
| Module # + title | Benefit-driven, not topic-driven |
| Rung advanced | Which ladder step |
| Big idea | One sentence |
| Install | What they DO in 10 minutes |
| Proof asset | Case study, demo, or exercise output |
| Objection pre-handled | Top doubt this module kills |

**Formats:** video lesson · worksheet · template · checklist · swipe file · community prompt

### Phase 4 — Mechanism Packaging

**Job:** Name the system so Schwartz stage 3–5 markets can differentiate.

| Element | Spec |
|---|---|
| **Mechanism name** | Ownable, searchable, memorable |
| **3–5 component parts** | Named sub-mechanisms |
| **Enemy** | Old method this replaces |
| **Reason-why** | Physics/logic of why it works (Hopkins) |
| **Carlton anchor** | Incredible hook → mechanics explanation |

**Schwartz link:** Stage 3+ requires mechanism. Stage 5 adds **person** (Celebrity engine).

### Phase 5 — Deliverable Stack

**Job:** Build Grand Slam stack — Hormozi value equation + Kennedy 5 elements. Stack until price feels trivial.

**Deep file:** `HORMOZI-METHODOLOGY.md` · **Template:** `research/GRAND-SLAM-OFFER-TEMPLATE.md`

| Layer | Examples |
|---|---|
| **Core** | Course / program spine |
| **Implementation** | Templates, swipe files, calculators |
| **Acceleration** | Office hours, hot seats, reviews |
| **Community** | Group, forum, cohort |
| **Bonuses** | Each solves one objection or speeds one rung |
| **Surprise** | Unannounced bonus at checkout (Halbert sweetening) |

**Value math:** Assign dollar value per item; total stack **≥ 10×** price anchor (Hormozi). Each bonus kills one objection.

**Haines rule:** Write **blind bullet stack** before finalizing modules — bullets reveal missing deliverables.

### Phase 6 — Pricing Architecture

**Job:** Price on transformation + stack, not hours.

| Element | Decision |
|---|---|
| **Anchor** | High-ticket reference or value stack total |
| **Core price** | Position vs competitors from Phase 1 |
| **Payment plans** | Halbert 30-day hold ×1.3 if applicable |
| **Guarantee** | Conditional double-money-back ×1.2 — terms explicit |
| **Risk reversal** | Abraham total risk shift |
| **Scarcity** | Cohort cap, bonus expiry — **true only** |
| **Reason-why** | Anniversary, charter pricing, etc. (Kern 4DCM) |

**Abraham lever:** Classify — does this offer move N, V, or F?

### Phase 7 — Launch Funnel Selection

**Job:** Pick one primary launch architecture; map every asset.

| Funnel type | Best when | Architecture |
|---|---|---|
| **Sideways Sales Letter (PLC)** | Warm list; story-led; stage 4–5 | PLC1–3 → open cart (`CRAFT-PLAYBOOKS.md`) |
| **Webinar / VSL** | Mechanism demo; cold+warm mix | Three Secrets → stack → close |
| **Challenge** | Community energy; daily installs | 3–5 day live + offer on final day |
| **Book funnel** | Authority play; low-ticket entry | Free+c shipping → upsell core |
| **4-Day Cash Machine** | Existing list; proven offer | Reason-why discount sprint |
| **Evergreen VSL** | Paid traffic; scalable cold | VSL → order form → follow-up |

**Kern GOO:** If launch fails, diagnose **which stage** — traffic, opt-in, show-up, belief, cart, close.

### Phase 8 — Copy-to-Product Map

**Job:** Every sales asset section sells a specific product element.

| Sales section | Sells |
|---|---|
| Headline / hook | Heaven state or mechanism curiosity |
| Lead / story | Hell state + bonding (Carlton) |
| Problem agitation | Cost of not climbing ladder |
| Mechanism section | Named system (Phase 4) |
| Bullet block | Module outcomes + bonuses (blind fascinations) |
| Proof section | Rung-specific testimonials |
| Offer reveal | Deliverable stack (Phase 5) — Hormozi Grand Slam walkthrough |
| Guarantee | Risk reversal (Phase 6) |
| CTA | Cohort / price / bonus deadline |
| P.S. | Second ad — urgency + bonus restate (Haines) |

**Carlton SWS:** Run full 17-step checklist on primary sales asset.

### Phase 9 — Backend & Ascension

**Job:** Design LTV on day one — not after launch panic.

| Backend type | Purpose |
|---|---|
| **Order bump** | Low-friction add at checkout |
| **OTO / upsell** | Complementary implementation (templates, done-with-you) |
| **Downsell** | Payment plan or lite version |
| **Ascension** | Coaching, mastermind, certification |
| **Continuity** | Membership, monthly templates, community |
| **Referral** | Affiliate or host-beneficiary (Abraham) |

**Halbert Step 7:** Same-day thank-you + immediate second offer (~20% take).

**Frequency lever (Abraham):** Backend moves F — often more profitable than new N.

## Product Type Playbooks

### Flagship Course

- 6–12 modules · transformation ladder · PLC or webinar launch
- Module 1 = quick win · final module = identity close
- Community optional but high retention

### Coaching Program

- Curriculum spine + access (celebrity layer)
- Application or qualification for exclusivity
- Hot seats map to rungs

### Membership / Continuity

- Monthly install ritual · fresh swipes/templates
- Retention copy > acquisition copy after month 3
- Churn objection: "cancel anytime" + win recap

### Report / Toolkit

- Halbert super-product model · single PDF + tools
- Shorter funnel · heavy bullet stack
- Upsell to course for implementation

### Certification

- License to teach mechanism · peer authority
- Highest ascension · strict completion criteria
- Borrowed credibility for graduates

## Common Failure Modes

| Symptom | Likely break | Fix |
|---|---|---|
| High refund rate | No quick win in Module 1 | Rung 1 in first session |
| Sales page converts, students ghost | Content dump, no installs | Re-spine curriculum |
| "Too expensive" objection | Weak value stack | Phase 5 bonus architecture |
| Launch spike, no LTV | No backend designed | Phase 9 before launch |
| "Sounds like everyone else" | No named mechanism | Phase 4 + Schwartz re-diagnosis |
| Copy feels disconnected | No copy-to-product map | Phase 8 alignment |
