## Quantified Value Equation Protocol (Offer Valuation)

Before any offer copy, run the **Offer Valuation Protocol**. **Template:** `research/QUANTIFIED-OFFER-VALUATION-TEMPLATE.md`

```
VALUE = (Dream Outcome × Perceived Likelihood)
        ÷ (Time Delay × Effort & Sacrifice)
```

### Optimization directive

| Vector | Maximize (numerator) | Minimize (denominator) |
|---|---|---|
| **Dream Outcome** | Identity transformation, specific numbers, category-defining result | — |
| **Perceived Likelihood** | Proof pyramid, mechanism, guarantee, "people like you" | — |
| **Time Delay** | — | Quick wins, speed guarantees, first result in X days |
| **Effort & Sacrifice** | — | Done-for-you, templates, DFY bonuses, fewer steps |

**Score each lever 1–10.** Fix weakest denominator lever first at sophistication 3+. Inflate numerator only after friction is crushed.

**Stack math rule:** Perceived stack value ≥ **10×** asking price. Each bonus must kill one named objection.

## Behavioral Economics & Cognitive Bias Matrix (Phase 9)

Embed these triggers in tactical persuasion architecture — ethically, with real proof (`CIALDINI-METHODOLOGY.md`).

| Bias | Mechanism | Copy move | Example frame |
|---|---|---|---|
| **Loss aversion** | Pain of losing > pleasure of gaining | Daily cost of inaction | *"Every week without this costs you $2,400 in leaked pipeline"* |
| **Anchoring** | First number sets reference | High-anchor before reveal | *"Agencies charge $15k/month — you get the install for $4,997 once"* |
| **Decoy pricing** | Middle tier becomes obvious choice | Good / better / best ladder | Pro tier positioned as "most popular" |
| **Hyperbolic discounting** | Immediate rewards outweigh distant | Short-term win + long-term transformation | *"First booked call in 14 days — build the $1M backend over 12 months"* |
| **Endowment effect** | Ownership feeling increases value | Future-pace as already theirs | *"Imagine opening Monday to 3 qualified applications already in your inbox"* |
| **Social proof** | Others like them succeeded | Volume + similarity | *"847 [avatar type] installed this in Q3"* |
| **Scarcity (true only)** | Limited access increases desire | Real caps, deadlines | Named seat count, cohort close |
| **Commitment & consistency** | Small yes → bigger yes | Micro-commitment ladder | Quiz → report → call → offer |

**Sophistication map:**

| Stage | Lead with | Proof emphasis |
|---|---|---|
| 1–2 | Dream outcome + direct claim | Demonstration |
| 3–4 | New mechanism + bias stack | Proof pyramid layers 1–4 |
| 5 | Identity + tribe + endowment | Peer + institutional proof |

## Believability & Proof Stacking Hierarchy (Proof Pyramid)

**Mandatory in every sales message** at sophistication 3+. Stack sequentially — never skip a layer because proof is thin; use `[PROOF NEEDED]` placeholders.

```
        ┌─────────────────────┐
        │ 5. Institutional    │  Credentials, press, certifications, patents
        ├─────────────────────┤
        │ 4. Peer Proof       │  Relatable user quotes, forum threads, DMs
        ├─────────────────────┤
        │ 3. Case Study       │  Before/after journey with numbers + timeline
        ├─────────────────────┤
        │ 2. Demonstration    │  Visual/mechanical evidence — screen recording, live demo
        ├─────────────────────┤
        │ 1. Social Proof     │  Volume of buyers, ratings, logos, "as seen in"
        └─────────────────────┘
```

### Layer specs

| Layer | Job | Minimum viable proof |
|---|---|---|
| **1 — Social Proof** | "Others bought" | Buyer count, star rating, logo bar |
| **2 — Demonstration** | "I can see it work" | Screenshot, video walkthrough, live mechanism |
| **3 — Case Study** | "Someone like me won" | Named avatar + before/after + timeframe |
| **4 — Peer Proof** | "My people trust this" | Verbatim quotes in their jargon |
| **5 — Institutional** | "Authorities validate" | Credential, certification, media mention |

**Placement rule:** Social proof early (above fold). Demonstration at mechanism reveal. Case study before price. Peer quotes at objection points. Institutional at risk-reversal block.

**Output tag:** Wrap in `<proof_stack>` with layer labels.
