# Marketing & Operations Planning Methodology

**Master planning doctrine for The Architect.** Nothing ships, spends, or runs without a plan row. Marketing and operations are **one integrated calendar** — not reactive tasks.

**One voice.** Plan first. Execute second. Measure third. Adjust the plan — never wing it.

## Planning in One Sentence

> **Every dollar, post, chapter, email, test, and hour is assigned on a calendar before it happens — with an owner, metric, and CTA — or it does not run.**

## Architect law (non-negotiable)

```
NO PLAN → NO SHIP
NO METRIC → NO CAMPAIGN
NO CALENDAR ROW → NO FACTORY RUN
```

**Applies to:** marketing · operations · content · launches · partnerships · ads · factory · consulting · opportunistic plays.

**Exception:** 24–48h reactive trend plays — must be **logged into the plan within 48 hours** and tagged `opportunistic`.

## Three planning horizons

| Horizon | Scope | Refresh | File |
|---|---|---|---|
| **Strategic (12-month)** | Products · revenue · OPEN months · catalog | 1st of month — roll forward | `PERSUASION-MECHANICS-12-MONTH-PLAN.md` · `factory/business-plan.json` |
| **Tactical (90-day)** | Content pillars · campaigns · backend · tests | Start of each quarter + monthly tune | `PERSUASION-MECHANICS-CONTENT-PLAN.md` · Guru Blueprint template |
| **Operational (weekly)** | Chapters · posts · emails · asks · tests | Every Monday W1 kickoff | `MONTHLY-MARKETING-OPS-PLAN-TEMPLATE.md` (week rows) |

**Cascade:** 12-month assigns the month → 90-day assigns pillars → weekly assigns days.

## Integrated month structure

Every month plan contains **both** stacks:

```
MONTH PLAN
├── STRATEGIC ALIGNMENT (from 12-month: mode · product · opportunistic)
├── MARKETING CALENDAR
│   ├── Week 1–4 content (Guru Blueprint WHY/WHAT/HOW/WHAT IF)
│   ├── Email sequences (indoctrination · launch · nurture)
│   ├── Launch window (if any)
│   ├── Partnership / JV actions
│   └── Paid tests (budget · variable · success criteria)
├── OPERATIONS CALENDAR
│   ├── Factory chapter targets
│   ├── Publish / ship dates
│   ├── Backend delivery (cohort · calls · deliverables)
│   ├── Weekly metrics review (Friday GOO)
│   └── Monthly plan refresh (W1)
└── SUCCESS METRICS (named numbers for the month)
```

## Weekly operating rhythm (planned blocks)

| Week | Marketing (planned) | Operations (planned) |
|---|---|---|
| **W1** | Month kickoff · calendar lock · content batch outline | Factory register · business-plan sync · metric targets set |
| **W2** | Execute content plan · email #1–2 | Daily chapters · list hygiene |
| **W3** | Execute content plan · email #3–4 · test launch | Daily chapters · backend asset build |
| **W4** | Promo week (if scheduled) · test results · next month prep | Ship Kindle/launch · GOO report · plan next month |

**Daily (from Powers + Stone):** Success canon 15 min → planned highest-$ task → one list touch → one ask.

## Planning gates (before execution)

### Marketing gate

- [ ] Asset on monthly calendar with date + platform
- [ ] Guru Blueprint module complete (or launch template)
- [ ] Client attraction 5A named
- [ ] CTA + metric defined
- [ ] Traces to product spine or approved opportunistic play

### Operations gate

- [ ] Task on monthly ops calendar
- [ ] Owner assigned (Samuel / factory / agent)
- [ ] Dependency noted (e.g. chapter 8 before launch)
- [ ] Ship checklist linked (factory launch / Kindle)

### Spend gate

- [ ] Budget line in monthly plan
- [ ] One variable to test
- [ ] Kill threshold defined before spend starts

## Opportunistic overlay (still planned)

OPEN months and ≤20% overlay **are pre-approved categories** — not improvisation:

| Pre-approved play | Must still plan |
|---|---|
| Webinar/challenge | Dates + 5 emails + script — 1–2 weeks before |
| JV launch | Burchard template filled |
| Trend reactive | Log within 48h · tag opportunistic |
| Consulting sprint | Proposal template + calendar slots |

**Slip-in rule:** Never cancel planned primary month work for opportunistic.

## Monthly refresh protocol (1st of month)

```
1. Roll 12-month horizon forward one month
2. Lock previous month metrics (actual vs plan)
3. Publish new month MARKETING + OPS plan (template)
4. Sync factory/business-plan.json current_month
5. Register active book/launch in factory/state.json
6. Week 1 content batch planned before first post
7. Powers scorecard targets set
```

## Ship Gate (planning compliance)

- [ ] This deliverable has a row on the active monthly plan?
- [ ] Marketing and ops calendars both updated for the month?
- [ ] No unbudgeted paid spend?
- [ ] Factory runs match planned chapter count?
- [ ] Opportunistic plays logged (if any)?
- [ ] Next month W1 prep scheduled?

**Galactic Phase 10:** Planning audit fails → do not SHIP until plan row exists.
