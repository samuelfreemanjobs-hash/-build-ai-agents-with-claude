# Marketing Agent Scaffold Manifest

Standard file tree for a new agentic marketing agent. Generated by `the-architect build-agent scaffold`.

---

## Directory tree

```
agents/<agent-slug>/
├── README.md
├── SYSTEM.md
├── AGENT.md
├── INVOCATION.md
├── QUALITY-RUBRIC.md          # symlink or copy from the-architect
├── EDITOR-PASSES.md           # optional subset
├── methodology/
│   └── README.md              # links to parent craft files or custom slices
├── projects/
│   └── .gitkeep
└── AGENT-BUILD.md             # build record from template

packages/<python-slug>/        # optional — monorepo runtime
├── __init__.py
├── config.py
├── prompts.py
├── tools.py
├── runner.py
└── __main__.py
```

---

## File responsibilities

| File | Owner layer | Must contain |
|---|---|---|
| README.md | Ops | Install, run, metric, archetype |
| SYSTEM.md | Voice | Identity, voice DNA, ship gate |
| AGENT.md | Runtime | Phases, tools, stop conditions |
| INVOCATION.md | UX | Brief template for operators |
| AGENT-BUILD.md | Meta | Completed MARKETING-AGENT-BUILD-TEMPLATE |

---

## Python package checklist

- [ ] `config.py` — `AGENT_ROOT`, `PROJECTS_DIR`, `SYSTEM_PROMPT_FILES`
- [ ] `prompts.py` — `build_system_prompt()` reads markdown stack
- [ ] `tools.py` — MCP server, `PHASES`, min 5 tools
- [ ] `runner.py` — `run_once()`, `get_api_key()` guard
- [ ] `__main__.py` — `run`, `chat` subcommands
- [ ] `pyproject.toml` entry if standalone package

## Inherit from The Architect (recommended)

New marketing agents should **import craft**, not duplicate:

| Need | Link / copy from |
|---|---|
| Rubric | `agents/the-architect/QUALITY-RUBRIC.md` |
| Editor passes | `agents/the-architect/EDITOR-PASSES.md` |
| Schwartz / Carlton / etc. | Reference paths in methodology/README.md |
| Galactic diagnostics | Phase 1 template path |

**Voice:** New agent = new SYSTEM.md voice spec. Structure = same as Architect.
