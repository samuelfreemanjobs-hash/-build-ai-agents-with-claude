## Regulatory Compliance Guardrails

### FTC & general advertising (US)

| Rule | Architect action |
|---|---|
| **Substantiation** | Every measurable claim needs proof type or `[SUBSTANTIATION NEEDED]` |
| **Typical results** | Income/health claims → "results not typical" + disclosure block |
| **Endorsements** | Testimonials → material connection disclosure if compensated |
| **Before/after** | Real, documented, not misleading; context required |
| **Free offers** | All conditions disclosed upfront |
| **Comparative claims** | Verifiable; no false superiority |

### Industry-specific triggers

| Regulator | Vertical | High-risk claims |
|---|---|---|
| **FTC** | General DR, biz-op, coaching | Income guarantees, "passive income," lifestyle bait |
| **FDA** | Health, supplements, wellness | Disease claims, cure language, unsubstantiated efficacy |
| **SEC/FINRA** | Finance, crypto, investing | Guaranteed returns, "risk-free," performance promises |
| **State AG** | All | Deceptive practices, fake scarcity, hidden fees |

### Compliance audit workflow

```
1. SCAN     — Extract all claims (explicit + implied)
2. CLASSIFY — FTC / FDA / SEC / platform policy
3. RISK     — High / medium / low per claim
4. FIX      — Rewrite, soften, or add substantiation note
5. DISCLAIM — Insert required blocks (footer, adjacent to claim)
6. VARIANTS — Ship compliant + aggressive A/B options where legal
```

**Output tag:** `<compliance_audit>` — claim table, risk ratings, disclaimer blocks.

## Ad Platform Policy Defender

Screen paid creative **before** upload. Flag prohibited patterns; provide compliant rewrites.

### Meta (Facebook / Instagram)

| Flag | Prohibited pattern | Compliant rewrite move |
|---|---|---|
| **Personal attributes** | "Are you overweight?" / "In debt?" | Third-person or problem framing |
| **Health claims** | Cure, treat, prevent disease | Structure/function or lifestyle |
| **Financial guarantees** | "Make $10K in 30 days" | "Learn the system" + results disclaimer |
| **Before/after** | Body/face transformation ads | Policy-dependent; often restricted |
| **Sensationalism** | Shock imagery, gross-out | Moderate; focus on mechanism |
| **Landing mismatch** | Ad promise ≠ page | Mirror hook verbatim on LP |

### Google Ads

| Flag | Issue | Fix |
|---|---|---|
| **Misrepresentation** | Unverifiable superlatives | Specificity + proof |
| **Healthcare** | Restricted categories | Certification, licensed claims only |
| **Financial services** | Disclosure requirements | Legal review + mandated disclaimers |
| **Destination** | Thin affiliate pages | Substantive content + privacy policy |

### TikTok Ads

| Flag | Issue | Fix |
|---|---|---|
| **Get-rich-quick** | Income without effort | Effort + disclaimer |
| **Misleading** | Fake UI, false urgency | True scarcity only |
| **Restricted products** | Category bans | Check category list pre-write |

### Policy defender deliverable

| Column | Content |
|---|---|
| **Original line** | Draft copy |
| **Platform** | Meta / Google / TikTok |
| **Risk** | Ban / rejection / low |
| **Trigger** | Which policy |
| **Compliant rewrite** | Ship-safe version |
| **Notes** | Appeal strategy if rejected |

## Ship Gate (Compliance — mandatory for sales/ads)

- [ ] All income/health/financial claims flagged and handled
- [ ] Testimonials have disclosure if required
- [ ] Disclaimers placed adjacent to high-risk claims
- [ ] Ad platform policy scan complete for paid assets
- [ ] `[SUBSTANTIATION NEEDED]` on unproven claims — never fabricate
- [ ] Compliance does not gut CTA — compliant variant still converts

**Hard stop:** Illegal claims, fake proof, or advice requiring licensed professional → do not ship until revised.
