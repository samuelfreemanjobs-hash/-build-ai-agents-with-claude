## 3A — Art Direction & Visual Brand Identity

### Aesthetic hierarchy

| Element | Directive |
|---|---|
| **Color psychology** | Trust (blues/navy), urgency (controlled red/orange accents), premium (black/gold/white space) |
| **Typography** | One display + one body; max 2 families; hierarchy via weight/size not font soup |
| **Layout spacing** | Generous white space = premium; Carlton theatre for copy blocks |
| **Contrast ratios** | WCAG-aware for body text; CTAs must pop |

### Visual conversion accents

| Accent | Job |
|---|---|
| **Color pops** | CTA buttons, guarantee badges, price callouts |
| **Direction indicators** | Arrows, gaze lines, numbered steps |
| **Focal points** | Single primary action per viewport |
| **Micro-animations** | Draw eye to CTA — subtle, not distracting |

**Victor Schwab link:** Headline selects + rewards — visual hierarchy does the same for the page.

## 3B — Digital Product Packaging Design

### Digital unboxing

Transform abstract software/courses into **tangible high-value assets**:

| Asset type | Packaging move |
|---|---|
| **Course** | Stacked module mockups, device frames with UI preview |
| **Toolkit** | Binder suite, tabbed workbook spreads |
| **Prompt pack** | Vault UI, card deck fan, terminal aesthetic |
| **Membership** | Portal dashboard mockup, community preview |

### Asset hierarchy formatting

| Element | Standard |
|---|---|
| **Workbooks / cheat sheets** | Polished headers, scannable callout boxes, numbered steps |
| **Diagrams** | One idea per visual; MECE framework graphics |
| **Typography in assets** | Match brand spec; readable at print + screen |
| **File naming** | Premium feel — not `doc_final_v3.pdf` |

**Hormozi link:** Packaging increases perceived likelihood (value equation numerator).

## 3C — Product Design & UX/UI

### Frictionless UX principles

| Principle | Implementation |
|---|---|
| **Zero-cognitive-friction onboarding** | One action per screen; progress visible |
| **Time-to-value** | First win in < 10 minutes (Pagan install) |
| **Navigation** | 3-click rule to core value |
| **Form reduction** | Minimum fields; social login when appropriate |

### Conversion micro-copy (UI)

| Element | Standard | Example |
|---|---|---|
| **Primary CTA** | First-person, outcome-led | "Send Me My Free Blueprint" |
| **Subtext** | Anxiety reducer | "No credit card required" |
| **Checkout** | Micro-guarantee beneath form | "Cancel anytime · 30-day guarantee" |
| **Error states** | Human, helpful | Not "Error 422" |

**Sugarman link:** Every element sells the next — including button labels.

## Visual + Copy Integration

| Page zone | Visual | Copy |
|---|---|---|
| **Hero** | Focal CTA, trust badges | Pre-head + headline + subhead (Omni-Format) |
| **Proof** | Faces, logos, screenshots | Specific numbers + names |
| **Stack** | Bonus mockups side-by-side | Objection-killer bonus copy |
| **Checkout** | Clean form, guarantee seal | 3-step offer close |

## Wireframe Deliverable Spec

When tasked with visual/packaging design, deliver:

1. **Mood / direction note** — palette, type, premium vs accessible
2. **Layout wireframe** — ASCII or structured spec (zones, hierarchy)
3. **Packaging mockup description** — what buyer "sees" in the stack
4. **Micro-copy table** — every CTA, subtext, guarantee placement
5. **Conversion audit** — focal point, friction points, eye path
