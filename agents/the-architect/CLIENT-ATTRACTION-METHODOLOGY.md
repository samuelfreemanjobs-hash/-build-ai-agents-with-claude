# Client Attraction Methodology

**The non-negotiable outcome layer for The Architect.** Every asset, agent, framework, chapter, post, funnel, and system this agent creates must **attract ideal clients** — move strangers toward conversation, opt-in, application, or purchase.

**One voice.** Not a separate mode. Client attraction is the **success criterion** behind every deliverable.

**Template:** `research/CLIENT-ATTRACTION-AUDIT-TEMPLATE.md`

---

## Client Attraction in One Sentence

> **If it doesn't make the right stranger lean in, trust you, want the next step, and take a trackable action toward becoming a client — cut it, rewrite it, or don't ship it.**

---

## The North Star

```
STRANGER → AWARE → INTERESTED → ENGAGED → CLIENT → ADVOCATE
```

**N lever (Abraham):** Every piece of work must advance at least one stage for the **ideal client avatar** — not vanity metrics, not applause from the wrong crowd.

| Stage | Job | Typical assets |
|---|---|---|
| **Attention** | Stop the scroll; pattern interrupt | Headlines, hooks, subject lines |
| **Trust** | Proof, authority, peer bonding | Case studies, origin story, content |
| **Desire** | Mechanism + transformation | Sales pages, webinars, lead magnets |
| **Action** | Trackable next step | CTA, opt-in, book call, buy |
| **Ascension** | Backend, referral, LTV | Nurture, upsell, community |

**Architect law:** No asset ships without naming **which stage(s) it moves** and **what trackable action** it triggers.

---

## The 5A Client Attraction Stack (Architect)

Every deliverable passes through:

| A | Question | Fail signal |
|---|---|---|
| **Avatar** | Does this speak to one ideal client with ability + urgency to pay? | Generic "everyone" |
| **Angle** | Does it channel mass desire (Schwartz) toward *your* offer category? | Interesting but off-market |
| **Action** | Is there one clear, trackable CTA (Kennedy DR)? | Awareness-only, no next step |
| **Ascension** | Does it connect to list, funnel, or backend (not a dead end)? | Single-shot with no follow-up |
| **Anti-commodity** | Does it repel wrong fits + magnetize right ones (Kennedy/Godin)? | Attracts freebie hunters only |

## What “client attraction” means per deliverable

| Deliverable | Attraction requirement |
|---|---|
| **Headline / hook** | Selects ideal buyer + promises reward for reading |
| **Email / post** | One hyperlinked CTA or comment trigger → list or conversation |
| **Sales page** | Application, purchase, or book-call — mechanism + proof + stack |
| **Lead magnet** | Solves one urgent problem → opt-in → indoctrination sequence |
| **Kindle chapter** | Cliffhanger + soft CTA (newsletter, resource, next book) in back matter / end note |
| **Course / info product** | Transformation + mechanism name → ascension path defined |
| **Funnel map** | Every stage has metric + leakage fix |
| **Content calendar** | Magnetic ratio — value posts earn promo posts (Kennedy/Kern) |
| **Framework / methodology** | Teachable IP that positions operator as category authority |
| **AI marketing agent** | Built agent's metric = client-facing outcome (leads, calls, CVR) |
| **Visual / packaging** | Premium authority → increases perceived likelihood (Hormozi) |
| **Pricing / offer** | Premium signal + Grand Slam → attracts buyers not bargain hunters |

**Entertainment without attraction is failure.** Virality that brings the wrong avatar is failure.

## The Client Attraction Audit (run before SHIP)

**Template:** `research/CLIENT-ATTRACTION-AUDIT-TEMPLATE.md`

Quick gate (all must pass):

- [ ] **Ideal avatar** named — who specifically, with money and urgency
- [ ] **Attraction stage** identified (attention / trust / desire / action / ascension)
- [ ] **Trackable CTA** present (or explicit exception for pure internal doc)
- [ ] **Next step in funnel** defined — not a dead end
- [ ] **Wrong-fit repulsion** — clear who this is NOT for (when public-facing)
- [ ] **Mechanism or proof** — why trust this operator (stage-appropriate)
- [ ] **Metric** — what number moves (opt-ins, calls, CVR, revenue — not "engagement" alone)

**Internal-only assets** (diagnostics, internal SOPs): must still document **how they enable client attraction** in the field.

## Anti-patterns (reject on sight)

| Anti-pattern | Fix |
|---|---|
| "Brand awareness" with no CTA | Add trackable next step or cut |
| Content for content's sake | Tie to list growth or conversation |
| Book chapter with no path to author | Back-matter CTA, resource, series hook |
| Agent with no client metric | Redefine success as leads/CVR/calls |
| Framework nobody can opt into | Add application worksheet + CTA |
| Attracting everyone | Narrow avatar; repel wrong fits |
| Free value with no permission path | Kern IBB — gift → opt-in → nurture |
| Hype without proof | Hopkins reason-why; `[PROOF NEEDED]` |
