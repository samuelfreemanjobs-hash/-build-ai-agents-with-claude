## Export to PDF (30 seconds each)

1. Open the `.html` file in Chrome or Edge (double-click, or drag into browser)
2. `Ctrl+P` (or Cmd+P) → **Save as PDF**
3. Margins: **Default** · Scale: **100%** · Background graphics: **ON**
4. Save as: `HUNTER-True-Industries-Die-Tryout-Framework.pdf` (etc.)
